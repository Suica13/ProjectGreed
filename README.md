# ProjectGreed V0.1

单位、武器套件、编组与部署的最新配置见 [单位与编组配置](单位与编组配置.md)。可用单位、各类防护、原 MOD 素材与音乐播放列表均由项目内 JSON 配置。

基于 Gundam Wars MOD 素材制作的浏览器回合制战术游戏原型。当前可用单位为 RGM-79 吉姆、RGC-80 吉姆加农与 RGM-79L 轻装吉姆，各有主武器套件和固定武装。支持保存编组、出生区部署、双人IP联机、离线热座和AI对战。右下角 BGM 播放器支持暂停、播放与随机下一首，六首曲目可离线循环播放。

单人离线无需运行服务器：直接打开 `public/client.html`，点击“单人离线 · 对战AI”。联机时选择“联机房间”，先在弹窗输入 IP 并连接服务器，成功后从分列房间列表加入或创建房间；可点击“刷新服务器列表”重新读取。对局中断线和刷新页面后自动恢复当前席位。

网页首先进入 Menu，主菜单和房间准备期间不绘制战斗场景。入房后可选择队伍1、队伍2或观战席，两队玩家均准备后开战；游戏中通过“房间席位”随时切换角色。点击“主菜单”需确认离开，退出只释放自己的席位，其余玩家仍留在房间。

## 从仓库启动

安装 Node.js 22 或更高版本，克隆仓库后在工程目录运行：

```sh
npm ci --omit=dev --ignore-scripts
npm start
```

发布版：<http://127.0.0.1:1313/>

开发者版：<http://127.0.0.1:1313/developer.html>

端口由根目录 `cfg.json` 配置。开发者版左下角可开启UI布局编辑；导出的布局保存到 `client/ui-layout.json`，再运行 `npm run build` 同步更新开发者版和发布版。

仓库保留已构建的 `public/*.html`，可直接用浏览器打开。联机时仍需运行服务端。仓库不提交 `node_modules`，首次运行需执行上面的依赖安装命令。

给玩家分发可直接使用 `dist/ProjectGreed-V0.1-client.zip`，解压后双击 `client.html` 即可离线游玩。修改源码后运行 `npm run package:client` 重建 HTML 和客户端 ZIP；打包脚本需要开发电脑安装 Python 3，玩家无需安装。

`project.json` 统一保存项目名称与显示版本，构建时注入网页，服务端启动与 `/health` 也显示同一标识。反击命中率为正常最终命中率的 75%。每次队伍交接递增回合编号，播放「结束回合 → 回合编号 → 开始行动」横向 Cutin。没有合法移动或攻击时等待 1 秒自动结束回合；联机由服务端计时。地图支持滚轮及按钮缩放至 300%，放大后按住拖动平移，点击「复位」显示全图。

## 开发检查

```sh
npm run build
npm test
```

详细玩法、局域网连接、断线恢复和UI编辑说明见 [使用说明](使用说明.md)。原始美术素材来自 Gundam Wars MOD。

开发者版支持独立场景预览、界面元素选择与拖拽、战斗机体位置和倍率调整，以及桌面／平板／手机布局。无需实际打一场战斗即可预览命中、未命中、反击和击破。

源码职责、可视化编辑步骤、JS 常用写法和检查命令见 [代码导读](代码导读.md)。

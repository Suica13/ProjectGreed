# 单目标自动攻击（2026-11-02）

本轮暂不引入小队、堆叠或地图格子尺寸变化。

- 玩家为每台单位指定一个敌方目标；再次规划替换原目标，不叠加多个目标。
- 武器由服务端选择，客户端不能指定、添加或删减武器。反击同样自动选择武器，但仍可选择反击目标、防御或回避。
- 每次交战：光束步枪3轮，光束喷枪/火箭筒/机枪/加农炮2轮，头部火神炮固定1轮，导弹发射器与其他武器1轮。每轮保留原武器的原生弹数、弹丸、部位与发射顺序。
- 攻击与反击暂时不要求、不扣除AP；武器配置中的AP保留，移动、占领、机体主动技能继续使用各自费用。
- EN逐轮支付；发射前检查EN、弹药次数、驾驶员条件、部位、炮塔射界与冷却。驾驶员限定武装仍受每回合一次约束。
- 迫击炮保留散布、核弹/爆炸武器保留范围；蓄力狙击自动锁定，下次己方回合射击。机体主动技能仍独立操作。
- 所有武器的现行射程（含分类覆盖及既有加值）乘0.5，向上取整，最低1格。人工差值仍在全局换算之后应用，原MOD基准不变。视野、索敌和光环范围不变。
- 服务端按“进攻一轮→反击一轮”交替执行；同一侧各单位可以并行，但必须等待本侧弹丸判定完成后才交给另一侧。回合数较少的一侧结束后，另一侧继续完成剩余射击。
- 所有射击结束后进入格斗。进攻方仅接近目标一次，在目标面前保持位置，双方按“进攻一件格斗武器→反击一件格斗武器”交替执行；一方结束后，另一方继续使用剩余格斗武器。结束后进攻方回到地图原格，不修改模拟位置或视野。
- 冲撞仅在格斗距离内、且格斗阶段没有其他可用格斗武器时启用。具有射击武器不妨碍冲撞，但不能把冲撞接在正常格斗序列后面作为额外攻击。
- 被击毁的单位不再进行后续攻击。
- 客户端播放权威时间轴，不以帧率、缩放或播放速度决定先攻、命中或格斗顺序。
- 共享单位的反击审阅、请求ID去重、revision校验，以及玩家/观战者演出完成屏障均保留。

实现入口：`shared/automatic-fire.js`、`shared/attack-plans.js`、`shared/rules.js`。
射程配置：`shared/conversion-rules.json` 的 `weapons.range=0.5`，不改写原始单位武器数值。

武器分类已改为单层类型，配置schemaVersion=3。取消身体/腕部/头部等分类以及部位伤害、固定AP/射程特例，详见 `../武器分类与换算规则.md`。

# 战略局地战地理生成

43个区域沿用原地图ID、57×68格、5v5、中心基地与六个据点的机制。北朝上，以 world.json 区块轮廓确定局地战取景范围，横纵使用相同投影比例，避免把海岸线拉伸成方块。矩形取景可能包含临近区域的陆地，并非行政边界裁切图。

地形采用战略地图海岸线和 Natural Earth 主要河流、湖泊、山脉、沙漠。森林按纬度带与固定种子生成，雪地按高纬度与苔原生成；这些是战术尺度抽象，不是精确地表影像。

为保持可玩性，基地和据点优先落在本区陆地，地面通路优先走陆地和山口，必要时补桥梁／堤道。海洋区域使用人工登陆平台；各通用部署区仅补足原验证要求的72格通行空间。人工平台、地面路径、投影范围与地形统计写入各地图 geography 字段，可用于审查。地理重做不修改出生区、补给线、占领、存档连续性等服务端规则。

战略连接与局地战入口同时生成。入口方位按相邻区域中心的相对方向确定，包括印度北部与哈萨克斯坦的南北入口。源连接必须同步维护 geography-source.json 和 world.json，避免重生成战略地图时丢失。

## 重新生成

生成环境需要 numpy 与 shapely，仅生成时使用，不加入客户端或服务端依赖。

```powershell
python tools/generate-campaign-maps.py --rebuild-geography --dependencies tmp/map-build-deps
npm.cmd run build
```

不带 --rebuild-geography 时保留已有地图；显式重建会覆盖43张局地战地形。已保存的局地战保留存档中的地图与单位位置，重建不会强行改写进行中的战局。

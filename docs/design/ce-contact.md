# CE0071T1 联络任务链

已接入运行时，数据来源为 `shared/contact-ce.js`。完成并交付联邦“小菜一碟”或吉翁“不可退让”后，同时开放地球联合军和扎夫特联络人；无须新建存档。未解锁时也显示两方卡片及“未解锁”，但不能接通。初见通信完成才发放基础科技及首项开发计划的生产许可。

联合军联络人仇视扎夫特与调整人，觊觎奥布的工业和质量加速器；扎夫特联络人高傲、歧视自然人，并认为奥布应放弃自然人市民。玩家在对话中坚持合同限于武装目标。两方任务各自独立推进，不互相排斥。

每条任务以前一条交付为前提；难度允许向上兼容，必须是CE0071T1地面合约、指定敌军阵营。任务事件追加于普通事件之外，不抬高普通事件结算完成率；需要成功撤离结算后才能交付。每项任务固定资金为`7500＋最低N级×4000`、好感度100；固定交付奖励不套合约全局倍率。发放许可覆盖两方科技树全部非占位T1节点，包含空中与水中分支。

任务守军与增援采用本阵营N级部队池，特殊歼灭任务使用明确列出的混编目标。普通驾驶员均为一般等级，不批量使用老兵。CE部队预算参考0079同级上调约10%，任务守卫、目标数量和设施另行配置，设计目标为略高于0079T1双边任务；实际难度仍需玩家持续试玩反馈。

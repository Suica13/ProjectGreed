# 0079T1 地球联邦军 陆地部队池

已接入UC_0079_T1地面合约刷兵。按N1至N6逐级排列，同一编队适用多个难度时分别列出。

## T1兵力走向

N1、N2为前期，N3、N4为中期，N5、N6为后期。同阶段内随N级增加编队规模与事件预算，不以大量稀有机体替代主力。

- 前期：61式主战坦克A5型、飞鳐和迪普罗格为常规兵力，少数吉姆初期型。
- 中期：陆战型吉姆及武器货柜型为MS主力，保留大量61式A5和常规飞鳐、迪普罗格；少数陆战型高达、吉姆狙击型和量产型钢坦克。N4开始加入部分吉姆及吉姆指挥官机编队，向后期过渡。
- 后期：吉姆为主力，部分陆战型吉姆，保留飞鳐和迪普罗格。N5为少数钢加农、钢坦克，极少数高达；N6将钢加农、钢坦克提高到部分，高达提高到少数，并允许钢加农三机、钢坦克三机以及高达／钢加农／钢坦克混编。

以下主力／常规、部分、少数、极少数表示抽取频度层级，不能将所有候选编队等概率抽取。末尾数字仍是兵力预算系数，与抽取概率分别管理。驻军、巡逻队、运输机载员及普通事件增援均沿用本级兵力走向；特殊剧情明确指定的单位除外。

## 说明

巡逻队每行为一个候选编队，末尾数值为难度系数，不是COST，也不是抽取概率权重。多个小队可同属一个编队。运输机后的/分隔数值依次表示各机载员部队的合计系数；也支持直接指定合计系数。防守友军据点不设初始敌方驻军。

狙击型按更高的兵力预算估值：吉姆狙击型单机按200系数估算，两台陆战型吉姆护卫合计50，整队250，避免以普通机体的低系数堆出过多狙击单位。驻军与增援的总预算保持不变，不因加入狙击单位追加预算。

常规部队优先使用科技树主线解锁单位，本稿不使用苍蓝宿命、苍白骑士、吉姆优越型、重装钢加农和钢坦克II等支线单位。中期陆战型高达、吉姆狙击型仅以单机配普通护卫出场；N4开始加入吉姆编队，N5起吉姆成为主力。N5的钢加农、钢坦克使用少数单机混编，高达极少数；N6的钢加农、钢坦克提升为部分，允许各自三机编队，高达提升为少数，允许高达／钢加农／钢坦克三机混编，每队高达仍最多一台。特殊剧情事件另行指定，不从常规池补入支线机体。本文为编队与预算配置源，构建时自动同步至shared/contract-force-pools.json。

实际刷新口径：主力8，部分／常规辅助4，少数1，极少数0.25的相对抽取权重。预算仅按每多一人+25%缩放，不再叠加旧人数换算，不拆分编队。环境适应性不足100%的单位不抽取（战蟹当前地面90%，含该机的候选队暂跳过）。普通边缘巡逻使用本级工厂被毁增援预算。

# 合约模式任务类型记录

本页记录合约地图上的事件目标，不是联络人的委托解锁树，也不是任务模式的固定地图剧本。联络人委托可以要求玩家在符合条件的合约中完成某类事件，但委托进度和事件完成是两个不同层面的判定。

## 当前已有类型

以下八种名称、类型ID与行为概述已核对`shared/contract-mode.js`中的`kinds`定义。具体数值和完整运行逻辑仍以共享代码及[合约模式规则](../rules/contracts.md)为准。

已制作[独立HTML策划编辑器](../tools/contract-event-editor.md)，内置以下八种类型及七种联络委托变体，按“概述与条件、触发与判定、兵力与增援、演出与奖励、改动与参考”整理。支持导入／导出JSON及导出AI交接Markdown；不会直接修改游戏。

| 类型ID | 名称 | 触发／操作 | 完成条件 | 失败、暂停或增援要点 |
| --- | --- | --- | --- | --- |
| salvage | 回收战场资料 | 进入白色3×3范围，选择单位并点击回收 | 消耗本次行动，立即完成回收 | 完成后从边缘运输追击；减量前基准为一艘运输机及三名乘员 |
| command | 消灭小股敌人势力 | 寻找标记为目标的敌人 | 消灭所有指定目标 | 指定目标与其他巡逻队分开计算 |
| factory | 破坏敌方工厂 | 攻击事件区域中的工厂 | 击毁所有目标工厂 | 攻击会引来支援；每座工厂被毁都会引来边缘巡逻队 |
| capture | 占领敌方据点 | 进入红色5×5范围启动占领 | 保持控制五回合 | 敌军进入时暂停占领推进 |
| defend | 防守友军据点 | PMC靠近至五格内启动 | 保护据点核心五回合 | 友军自动防守，敌军分批来袭；核心被毁则事件失败 |
| rescue | 救援失联小队 | PMC靠近至五格内启动 | 掩护友军三回合，至少一台存活 | 友军全灭则事件失败 |
| upload | 上传战场数据 | 进入蓝色3×3范围启动 | 保持区域内有PMC且无敌军三回合 | 离开或受敌军干扰时暂停 |
| radar | 摧毁敌方雷达站 | 靠近或攻击雷达设施 | 击毁雷达设施 | 靠近或攻击后会引来一批守卫增援 |

## 数量、回合与共用规则

- 普通事件数等于N级，基础八类优先不重复抽取。当前房间开放N1～N6及0079T1／0079T2，其他年代仍锁定。
- 驻军基准为 `3＋floor((N−1)/3)` 台，按参战玩家数缩放；只响应所属事件或本队发现敌人，不会因其他事件激活被吸走。
- 工厂有 `2＋floor((N−1)/4)` 座，雷达站一座；单座耐久 `20000＋5000×(N−1)`。工厂每毁一座仅触发一次边缘增援。
- 占领累计五个完整己方回合，启动当回合不计；经过第三个回合空降，之后每四个回合边缘增援。失去PMC或敌军进入只暂停，保留进度。
- 防守目标为一座核心、两座炮塔及三台友军MS。核心耐久 `40000＋5000×(N−1)`；启动及经过二、四回合有攻击波，保护五回合即可。核心被毁只使本事件失败；启动后不要求PMC一直留守。
- 救援有三台半耐久友军MS，PMC在五格内掩护累计三回合，至少一台友军存活；启动及第二回合增援。PMC离开暂停，友军全灭失败。
- 上传在3×3范围有PMC且无敌军时累计三回合；启动空降一次。雷达站激活仅响应一次空降增援。
- 后续增援统一乘75%并套用多人倍率、累计取整；每四个完整己方回合有全局边缘巡逻。N1～N6的增援存活上限为24／27／30／33／36／39台。满额跳过，不补发。
- 多人事件共享进度、演出不阻塞他人。普通事件完成计数影响最终收益，完成所有目标或全歼当前敌人不会结束合约，仍须撤离。完整收益与环境规则见[合约规则](../rules/contracts.md)。

## 联络委托追加的七种变体

这些变体复用基础事件机制；enemybase为本次新增的专属基地目标，不加入普通随机事件池。任意参战玩家接取相应委托后，在地面且达到最低难度时固定追加；通常要求敌军吉翁，efsf-7要求敌军联邦。同一委托全房间只生成一个。不占普通事件数量，也不增加普通合约事件收益，委托另行交付奖励。

| 委托ID | 事件名称 | 基础类型 | 最低难度 | 特殊构成与判定 |
| --- | --- | --- | --- | --- |
| efsf-2 | 坠落米迪亚的数据 | salvage | N1 | 米迪亚残骸，回收后接取玩家须成功撤离 |
| efsf-3 | 记名联邦MS小队 | command | N1 | 三台记名陆战型吉姆，联邦老兵驾驶员，替代普通驻军 |
| efsf-4 | 硝烟野餐：吉翁驻军 | command | N2 | 十二台扎古2F为指定目标，替代普通驻军 |
| efsf-5 | 苍白骑士实战测试 | factory | N2 | 四工厂、十二驻军、四炮塔；另记录苍白骑士击破工厂0/4。当前全队共享击破记录 |
| efsf-6 | 运输车队残骸 | salvage | N3 | Type74残骸，调查后接取玩家须成功撤离 |
| efsf-7 | 不死的雷纳斯小队 | command | N3 | 敌军联邦；老兵陆战型吉姆三台，机枪、火箭筒及光束步枪各一台，全灭目标 |
| efsf-9 | 往事速递的敌军基地 | enemybase | N3 | HQ一座、驻守MS十二台、炮塔四座；摧毁HQ后接取玩家须成功撤离 |

首秀（efsf-1）、最好的差事（efsf-8）和艺术就是爆炸（efsf-10）统计击破数，不额外生成地图事件，因此未计入变体；艺术就是爆炸仅记录迫击炮／炮击轰炸技能击坠。接取武力说服时获得的苍白骑士属于联络委托初始装备，不是地图事件奖励，完成目标后结算时自动卸下零件、解除驾驶员配属并回收借用机体。

## 新增类型策划模板

以下是记录模板，不代表新增玩法已实现。

| 项目 | 策划填写内容 |
| --- | --- |
| 名称／建议类型ID | 玩家可见名称与稳定标识 |
| 状态 | 草案／需要调整／有变动／废弃／已实现 |
| 叙事背景 | PMC为何接受该目标、需要取得什么结果 |
| 适用条件 | 难度、年代、阵营、环境及地图区域要求 |
| 发现与触发 | 靠近、主动操作、回合触发或其他条件 |
| 完成条件 | 数量、持续回合、指定单位、回收或撤离要求 |
| 失败／暂停条件 | 保护对象损毁、区域失守、超时等 |
| 驻守兵力 | 单位构成、套件、驾驶员与警戒范围 |
| 巡逻／增援 | 何时出现、进场方式、数量和存活上限 |
| 多人判定 | 任意玩家触发、全队共享、个人进度或房主决策 |
| 提示与演出 | 地图标记、范围覆盖、进度条、CUTIN和对话 |
| 奖励 | 是否仅计入完成事件数，是否还有额外收入、单位或许可 |
| 特殊情况 | 全灭、提前撤离、运输单位内目标、断线重连等 |
| 实现记录 | 对应源码位置、验证情况与待解决问题 |

后续具体任务类型可在本页继续追加；较长方案可在本目录单独建立MD并登记至[目录索引](README.md)。

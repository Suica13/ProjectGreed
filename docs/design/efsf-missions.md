# 联邦委托关卡

运行时任务位于 `shared/contact-efsf.json`，仅两个特殊关卡由 `tools/build-efsf-missions.cjs` 生成到 `assets/maps/missions/efsf_19.json` 与 `efsf_29.json`。其余27项通过合约累计击坠或专属事件完成。对白、目标和交付对白保留初稿原文。联络人按初稿顺序解锁，T2从“踩点行动”开始，以“权必有责”及GP计划结束。

关卡是初稿的游戏化改编。马卡丹、战区59、雷纳斯、特丽娜与卡辛沿用初稿设定，不宣称是原作事件。阿巴瓦库采用宇宙要塞、狭窄通道及连续增援，参考[阿巴瓦库背景](https://gundam.wiki.cre.jp/wiki/%E3%82%A2%E3%83%BB%E3%83%90%E3%82%AA%E3%82%A2%E3%83%BB%E3%82%AF%E3%83%BC)。SIDE6采用殖民地外围宙域，NT-1试验机背景参考[Sunrise作品介绍](https://www.sunrise-inc.co.jp/work/detail.php?cid=59)。GP02追击与殖民卫星拦截参考[0083官方剧情](https://www.gundam0083.net/story/)；阻止坠落的胜利结局按用户初稿制作，属于改编分支。

0079T2是项目科技阶段，不表示所有剧情都发生于UC0079。初稿中的0083相关机体与事件仍归该阶段。

T2委托难度从N3起步：16～18项N3，19～21项N4，22～25项N5，26～29项N6。T2合约对应编组额度为9000／13500／18000／22500 COST。特殊关卡沿用相应难度额度：阿巴瓦库13500、殖民卫星拦截22500。任务20「往昔时光」改为宇宙合约累计60台吉翁MS击坠，不再一次额外生成60台指定目标，可跨局完成；原已完成待交付记录保留，未完成的旧事件从累计0开始。

同N级比较时，0079T2的相对战场压力目标为0079T1的1.25倍，双方使用各自时代与阶段的单位池。`ContractForces.eraPressure`单独管理该倍率；玩家COST的时代补偿仍为1.5倍，不能将其误改为难度倍率。T2普通初始敌军N3～N6分别为23／30／38／45台，对应T1的18／24／30／36台；按单位取整，不在N3向上凑成24台。普通守军和增援共用压力倍率、累计取整与存活上限，初始配额补齐不再次乘倍率。未来配置的编队预算路径也只乘一次。单位原生属性、机师档位、奖励、任务原文及专属目标数量均不乘倍率。

1.25是同阶段编制压力的设计目标，不是已测得的通关率或战损比例；T1地面采用预设编队、T2采用阶段单位池，其武器和任务机制仍有差异。两张剧情地图没有同N级的T1对应关卡，保留另行指定的1.5倍敌我编制、五轮增援和198敌军／16舰上限，不再叠加普通合约的数量倍率；仍需通过实战反馈校准剧情关卡的体感难度。

合约任务支持歼灭、特定机体／套件击坠、接近侦察、回收后撤离、护送、不得伤及指定目标。特殊关卡支持坚守撤离和限时控制点操作。坐标标记显示在战场上，实际进度由服务端维护，查看快照不会增加进度。侦察点被摧毁前必须完成侦察；指定机体／套件不符的击坠不计入累计进度。接近哥伦布开始护送，由友军AI逐回合向撤离区移动；运输船被击毁失败。

阿巴瓦库至少击坠1架MS，坚持至18回合并返回撤离区；全队击坠数保存到任务进度，交付时每架计1000资金。殖民卫星关卡在24回合内清除守军，接近两个姿态控制点与轨道控制点，并保全阿尔比昂。

两个特殊关卡的资金、物资、机体、科技与驾驶员经验奖励均为零，任务交付奖励独立发放。首次接取解锁关卡，完成后仍可重玩；只有入场时已接取且尚未完成的任务可获得完成进度。旧任务关卡保留源数据，但从选单隐藏，并拒绝新建或切换进入。

每张地图保留五个合作席位，使用共享的紧凑部署区。部署区与敌军部署区分离，地形及路线使用项目既有素材。金额标为待议的任务采用暂定值，可在任务JSON调整，无需修改关卡战斗奖励。

## 舰队规模与增援

阿巴瓦空为44×64，自下而上进攻，上方为要塞，下方为玩家共享部署区与撤离区；殖民卫星拦截保持64×44。保留紧凑玩家部署区与三条交战通道。初始22个不可控友军、33个敌军；每方本批损失过半后独立触发下一批，最多各五轮增援，每批仍为22／33，包含舰内搭载机体。敌我1.5倍按剧情部队编制计算，不含玩家自带单位，也不意味着战损后的在场比例恒定。

全程上限为132个友军、198个敌军，敌军战舰合计16艘，包含在198中；初始不算增援轮次。每个事件只执行一次，重连／重复轮询不补发。不是固定回合刷兵，也不会复活同一实例。双方MA、阿鲁比昂和西玛只出现一次。

阿巴瓦空：每批友军由麦哲伦后期型、萨拉米斯后期型、哥伦布各一艘，以及19台吉姆、后期铁球与全装甲高达FA-78-1组成，其中FA-78-1每批仅一台。按各舰真实格纳库容量预先搭载，余下机体在舰外护航，舰载机由友军AI接敌后出击。敌军以姆塞后期型（项目0079阶段的改良姆塞）与巴布亚为中心，展开勇士、扎古II F2后期型、宇宙用力克大魔。初始和后续五批均使用同一阵容规则，敌军战舰总数仍为16艘。

殖民卫星拦截：西玛的勇士海军型部队与联邦吉姆改／特装型／加农II混编，阿鲁比昂和莉莉·玛莲协同；敌军为姆塞后期型0083、扎古F2、勇士海军型、力克大魔及II型。友军石斛兰、敌军路维·捷露各一台。初始守军仍是控制点解锁目标，后续增援持续施压但不追加到必须清空的守军清单，避免控制点随增援无限锁定。

开场使用带单位镜头定位的舰队通讯，增援时发送轮次和数量提示。对话为关卡原创；西玛与联邦协同并成功阻止坠落是按用户要求制作的改编路线，不复现原作友军冲突。参考[官方西玛勇士M及莉莉·玛莲介绍](https://gundam-official.com/news/i/news/goods/01_10600)、[官方路维·捷露介绍](https://gundam-official.com/news/i/special-series/ms-pb/special-series_ms-pb_20091016_366p)。现有素材未单列莉莉·玛莲与原版大丁草：前者使用桑吉巴尔改0083舰体，西玛驾驶现有勇士海军陆战队指挥官型，不使用后世大丁草改冒充原版。

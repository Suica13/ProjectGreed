# 驾驶员天赋：50项

状态：已接入自定义PMC驾驶员。招募时没有天赋，首次达到4级随机获得第1项，第一次转生获得第2项，第二次转生获得第3项；后续转生不再增加。最多三项且互不重复。已有驾驶员保留已获得天赋，按等级和转生次数补齐。转生和降职保留天赋及已解锁次数，补齐结果随档案保存，不因读档重抽。ACE及一般PMC驾驶员不获得这些天赋。

## 计算口径

- “系数+5%”表示该系数乘以1.05，不是最终命中率增加5个百分点；系数负向修正同理。
- “伤害+10%”表示对应伤害乘以1.10，不额外增加攻击次数。
- 觉醒值、指挥范围和明确标为“个百分点”的效果采用直接加减。格挡率继续遵循现行75%上限。
- 以下涉及耐久比例、距离与环境的条件，均以驾驶员当前搭乘单位为准。射击不包含格斗；格斗不包含射击。
- 同类天赋加成先加总后统一计算。天赋不额外增加COST。
- 情境条件在实际攻击、应战和移动查询时判断；武器类别按游戏内武器分类识别。效果定义见 shared/pilot-talents.json。

## 实现口径

- 所有50项均在随机池中，正负面可组合，不自动更换无盾牌等情况下暂时无效的天赋。
- 夜间为傍晚、深夜、黎明前；地面／宇宙／水下依据单位实际环境。小队人数为同玩家同格存活且未搭载的单位数量。
- 格子距离沿用战斗距离；远射为4格及以上，贴身格斗为1格。
- 光束／实弹专精只作用于对应射击伤害分量，包含穿甲分量；加农、导弹、狙击等按武器分类识别。
- 天赋仅影响武器EN消耗，不影响单独的技能EN费用。EN费用向上取整，重复预览不重复叠加。
- 随机结果以驾驶员ID及槽位稳定生成并保存；新招募使用随机ID。旧存档补齐不需要额外花费。

# 编辑修改记录

- EFSF、ZEON、AEUG、TITANS、NEO_ZEON：各阵营单位库的成功编辑记录。共享机体会登记到所有可用阵营；详细JSON日志只生成一次。
- global-rules：全局数值换算规则，单独记录，不把每次倍率修改复制进所有阵营文档。
- common-weapons、wip、OTHER：没有对应单位的共用模板、WIP或其他改动。
- legacy：旧版集中登记表的历史归档，升级后不删除原记录。

服务端按同一事务保存源JSON、差值、审计JSON与Markdown，失败全部回滚。文件修改不会触发客户端自动构建；管理员完成编辑后按需重建。

开发者HTML登录前先选择一个阵营，只下载该阵营可用的单位与武器数据；右上角切换阵营，已下载的目录在本次会话缓存。保存修改后作废缓存并仅刷新受影响的单位。关闭预览或取消编辑不发起目录请求，也不读取个人进度、播放BGM或下载单位贴图。

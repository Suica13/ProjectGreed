# 房间与地图

游戏服务端默认监听1313端口，读取cfg.json；玩家连接同一服务端后创建或加入房间。模式、房间锁、队伍、阵营、AI与编组上限由房间界面及shared/room-rules.js配置维护，不在本文重复固定预设表。

房间支持出战和观战席位。动作必须携带唯一请求ID及revision，由服务端校验；重复请求不重复结算。共享单位应战按玩家并行收集，统一裁定，观战者同样参与演出完成屏障。

地图分遭遇战和战略剧本目录，具体结构见[地图目录](../maps/map-layout.md)。战略模式有独立的5v5剧本设置与局地战地图，普通遭遇战使用地图登记的出生位与部署区，不把所有地图写死为左右两条部署带。

房间内切换机库、生产、开发不离开房间。进入战斗后沿用战斗UI。设置、离开及玩家席位在对应场景中提供；具体状态限制由room-engine和campaign-room维护。

全局战场规则按对战模式、战争迷雾、友军单位共享、驾驶员启用、战场对话排序；天气与昼夜设置单独折叠在最后。雇佣兵战争的年代、双方阵营与作战规模在自己的设置框中维护，自定义数值不再与普通编组限制重复显示。

## 雇佣兵战争地图与席位

现有三张专属地图：环峡高地72×48格、双脊峡口64×44格、裂谷遗迹64×44格。每张均有双方各一个主基地、四类炮塔和雷达，以及四个中立据点；使用可编辑TileMap、实际地形与地表装饰，并保留天气和昼夜配置。双脊峡口以中部谷道和南北双层山脊形成主路／侧翼路线；裂谷遗迹采用西北与东南基地、环形高地及中央遗迹盆地。

最多每队6个席位：1号位固定阵营AI，剩余5位供PMC玩家或普通AI使用，合计最多10名人类参战。出生点采用二维簇，同队共享部署区；新增席位不要求沿水平／垂直单向扩展地图。同队部署区允许重叠，敌队仍须分离。普通遭遇战和历史战役的既有地图人数保持不变。

重建原图使用 `node tools/build-battlefield-map.cjs`，重建两个变体使用 `node tools/build-battlefield-variants.cjs`；后者沿用原图的峡谷图集与设施素材。地图编辑器默认也使用紧凑的同队共享部署区，可编辑每队最多6个席位。

## 常规战 AI 的年代范围

常规战 AI 只能选择所有参战人类玩家编组内出现过的年代标签所涵盖的单位，两队共同取并集，预先搭载单位也计入，观战者不计。单位拥有多个年代标签时，命中任意一个即可；科技、COST、禁用单位等既有限制继续生效。最终编组阶段玩家更换单位导致年代范围变化时，AI 编组会刷新，进入实际部署后固定本局范围。

快速战和历史战役保持原有年代规则。没有人类参战的纯 AI 房间保留原候选池，恢复战局存档时保留已有编组。

## 遭遇战 TileMap 与环境

现有17张遭遇战地图均维护可编辑的 TileMap、与游戏裁定一致的地形格及环境配置。14张旧地图使用按地貌生成的四种地表变体；3张已有手绘背景的地图保留原背景及地形标注。地图尺寸、出生点、部署区和水陆通路保持原布局，极地的平地细分为雪地，沙海的平地细分为沙地，移动与掩护仍由共用地形规则裁定。

| 地貌／地图 | 默认天气倾向 | 昼夜 |
| --- | --- | --- |
| 极地遗址、融冰河谷 | 雪、阴天、晴天和雾；融冰河谷允许少量降雨 | 八阶段循环 |
| 风蚀沙海 | 以晴天为主，可出现沙尘和沙尘暴 | 八阶段循环 |
| 林地、高原、大平原 | 晴天、阴天、降雨和雾 | 八阶段循环 |
| 蛇河雨林 | 提高降雨、暴雨与雾的权重 | 八阶段循环 |
| 海陆补给线、质量投射设施 | 潮湿沿海天气，允许暴雨 | 八阶段循环 |
| 都市断层、联合军事基地 | 以晴天为主，允许阴雨和雾 | 八阶段循环 |
| 殖民卫星内部 | 固定晴天，不生成室内降水及地表积雪 | 人工照明昼夜循环 |
| 所有宇宙地图 | 无地表天气、覆盖或日照阴影 | 无昼夜 |

房间设置中的“天气与昼夜设置”为独立折叠框，默认收起；房主可覆盖天气、时段、循环和视野影响。各图的具体权重与回合周期保存在地图 `climate` 字段。维护脚本为 `node tools/rebuild-encounter-maps.cjs`，加 `--check` 只校验不写入。

单位阴影先合成所有可投影零件，再统一施加地图阴影透明度，零件重叠不会叠加变黑。天气与时段仍可整体调整阴影强度和方向；不是逐零件分别调整透明度。

## 战斗地图缩放

缩放百分比按当前地图与画布的实际可缩放范围计算：0% 为全图之外再缩小一级的单位图标视图，1% 为完整地图，100% 按最多横向8格、纵向4格的近景确定。格子始终为正方形，因此屏幕比例不同时其中一轴可见格数会更少。按钮、滚轮与双指缩放共用此范围；重置按钮回到1%。

驾驶员名称和头像从统一缩放50%开始显示，字体与头像保留可读的最小屏幕尺寸；对话气泡使用相同的50%门槛。5%及以下只保留单位占格轮廓、图标及其角上的驾驶员头像；交战时不播放机体姿态动画，子弹、命中与爆炸特效保留。

5%以上、25%以下的远景使用有内存上限的主体图片复用：单张边长上限2048像素、总像素预算32Mi（报告内存不超过2GB的设备为16Mi），身体待机姿态最多按12帧/秒更新，按预算轮流刷新缓存，画布反复使用，缩放与平移只改变投影。发动机、旋转层及其他特效仍实时绘制；移动中的动态姿态只允许同帧同一时刻复用，否则实时绘制。25%及以上恢复原始图层与当前动画时刻绘制，不复用降精度主体缓存。上述表现处理不改变服务端裁定与动画时间轴。

战场驾驶员头像首次加载后裁成64像素缩略图复用，最多保留512张并限制并行加载数量，避免大编组在缩放显示头像时反复解码原图。

换图、同图重新开局及退出战斗均按对局ID管理演出资源：释放上一局的地图分块、单位姿态、阴影、描边、雾层和天气缓存，清除旧地图图集及不再使用的已解码战斗贴图；菜单头像与下一局共用资源保留。过期异步加载不重新填回缓存。仅在当前对局内切换机库或接收普通快照不会重复清理。

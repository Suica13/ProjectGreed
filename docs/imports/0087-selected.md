拟阿卡玛高能MEGA炮接入既有方向照射技能，射程10格、宽度3格、原始基础命中50%（最终值继续应用现行全局换算），不再重复作为普通武器发射。Mk-IV保留1枚INCOM、合计8次原生发射；Mk-V保留2枚INCOM、合计16次发射。原生同名子单位的多个生成项和乘数均独立计数。

保留原始工厂价格、生产数量与时间，使用共用生产周期和部署许可换算。非战舰单台生产的特装机COST沿用现行全局倍率；人工差值仍最后应用。详细来源与基础数值见[结构化移植记录](0087-selected.json)。

## 量产型钢加农II同步削弱

`python tools/sync-0087-guncannon-ii.py`只刷新RX_77D_4的原生机体数值，不重建武器、套件、贴图或人工差值。来源为同包`Units/BattleUnits/RX_77D_4/RX_77D_4.ini`；原生武器载荷与发数未变。

| 参数 | 调整前 | 同步后 |
| --- | --- | --- |
| 原生耐久 | 30000 | 27500 |
| 战术耐久（原生×1.25，按500取整） | 37500 | 34500 |
| 射击系数 | 155 | 145 |
| 命中系数 | 145 | 135 |
| 原生推进速度 | 1.65 | 1.60 |
| 战术速度 | 120 | 115 |

移动基础值受现有取整规则影响，仍为7，经全局移动换算后为4格；EN700、反应125、基础COST625及武器原始伤害保持不变。全局换算和人工差值仍在运行时统一应用。

## ZZ系列光束步枪

强化型ZZ与全装甲强化型ZZ的AEUG_MSZ_010S_BR（含右侧炮口）在共用加载阶段沿用普通ZZ的AEUG_MSZ_010_BR数值及四发射击流程。伤害、穿甲、命中、射程、EN、攻击轮数与弹速统一，保留各自枪口、武器ID和贴图。原始MOD载荷、两发时间线及弹体参数保留在nativeSourceData中，运行时仍按全局换算、人工差值及取整顺序处理。

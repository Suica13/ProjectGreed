# 单位零件图标

现行18张图标为64×64的简约线条 SVG，存放于 `assets/ui/unit-plugins/`。深蓝底色、统一青色线条、不使用纹理或复杂机械细节。图标与 `shared/unit-plugins.json` 的ID对应，构建时内嵌到独立HTML；运行时不依赖生成工具或原始大图路径。

同目录 PNG 为先前使用内置 image_gen 生成的版本，当前客户端不再加载；下列提示词和主体表仅记录旧版图片来源。

生成提示词统一要求：低饱和像素风科幻机甲战术游戏的单个方形装备图标；正交技术插图，深海军蓝背景、灰钢材质、克制的青色指示灯，轮廓清晰，适合缩小到64×64；主体约留10%边距，无人物、机甲全身、文字、数字或UI边框。

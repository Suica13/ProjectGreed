# V121 发布验证

本次发布包含此前未提交的编组、任务、地图编辑器、SEED／0093 科技与单位移植工作，以及本轮 SEED 装备修复。具体来源及机制见 [SEED 清单](../imports/seed.md)、[装备修复](../imports/seed-corrections.md)、[现行战斗规则](../rules/combat.md)。

## 本轮结果

- 巴库恢复磁轨炮／导弹双套件、炮塔、原生发射序列及炮口；空中霸王按套件筛选机体装备图层。
- 核对实际磁轨弹药，修正对应名称和原生发射速度来源；沙漠型吉姆的导弹管仍按导弹处理。
- 指定的武器命中、射程、轮数、伤害、机体耐久与 COST 已通过人工差值事务保存；原 MOD 三台单位 UnitLevel 各只修改一行。
- 迅雷光学迷彩支持回合耗能、回避系数、索敌隐身、攻击解除及机体／阴影透明度。
- 编组、生产与添加单位的阵营标签使用统一科技阵营配色。

## 验证

- 定向 Node／真实 WebSocket：37 项通过，覆盖新修复、SEED、0093、科技主线前置、AP参考约束、整数数值、伤害取整、并行攻击与演出确认。
- 桌面／手机浏览器：8 项通过，覆盖科技树、房间设置、套件图层与颜色。最终图层补充检查再次通过；已查看渲染截图。
- 文档链接及自动生成的战斗规则检查通过。
- Windows 编译成功，文件版本0.121.0.0；Android APK签名校验通过。Gecko APK提供通用、arm64及armv7包，未变更安装身份或签名密钥。
- Windows、Android、服务端共4,906个清单文件哈希一致；独立HTML与服务端HTML一致。使用包内Node启动服务端并成功请求首页，验证后关闭。

## 验证边界

额外选取的旧测试存在8项不通过，涉及固定命中系数、旧伤害期望、烟幕机体列表、LPC记录、Pixy测试场景、步兵发数及旧编组UI结构；未为消除这些断言而调整现行规则。本次定向检查通过不代表全量测试通过。

尚未进行安卓实机操作、所有65台SEED机体逐招动画人工验收或长期多人战局性能测试。详细测试日志和截图保留在项目 `tmp/verification/`，不随发行包交付。

发行目录为 `build/V121/`，包含Windows文件夹、Android Gecko APK、独立HTML、含HTML的服务端文件夹。首次Windows还原遇到NuGet SSL连接失败，重试使用本机固定依赖缓存并关闭在线NuGet审计后成功。

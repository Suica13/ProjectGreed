# V123 地图与合作任务

新增雇佣兵战争地图：小行星回廊、沉舰宙域、月面轨道（宇宙）；红树林三角洲、冰封盆地（地面）。新增快速战：雨林河口、冰川隘口、沙海中继站、废都河滩、轨道残环。共享部署区保持紧凑，地图使用现有模块生态图集、岸线、道路与装饰。

任务目录含联邦六关和吉翁六关。原任务改名为[0079][EFSF]孔斯空域的遭遇并保留原奖励；其他十一关暂不设奖励。Side 7、突入、加尔玛、兰巴·拉尔、贾布罗、所罗门等背景参考[万代频道0079动画介绍](https://www.b-ch.com/titles/929/001)，属于供PMC参与的游戏化改编，新增对白为原创，不视作动画逐字剧本。吉翁侧任务为相应战役的反向或撤离视角，不重写动画结局。

四关含增援剧情攻击。地图编辑器的剧情攻击动作选择攻击方和指定敌方脚本单位，服务端一次性裁定击破，客户端播放射击姿势、弹丸和击破效果。动作与对话一样随事件完成标记去重；剧情攻击不额外触发普通武器数值结算。

战舰对空炮恢复普通1—2格武装；核心推进器光束枪降低50%，沿既有25点取整。雇佣兵战争取消随机舰船，每座主基地每波固定一台运输单位。0079T1地面为米迪亚／胖叔叔，宇宙为哥伦布／巴布亚；后续UC年代改为米迪亚改／胖叔叔改、哥伦布改／帕佐克。宇宙固定兵力替换坦克与地面飞机，随机池按环境适应性筛选。

# V80 更新与验证

- 修复狙击蓄力使用了锁定辅助贴图和超低弹速导致演出迟迟不结束的问题；下一己方回合射击后可以继续操作其他单位。
- 修复连续小队格斗、闪避与朝向显示，恢复冲撞兜底；演出异常会提示并保持渲染循环，避免所有单位消失后画面永久停止。
- 小队保持最多6台／6容量点，使用自动三角列队；全队按钮在头像左边，格斗战按钮移到同一行并与头像等高。确认后的普通攻击计划可以重新打开、改目标或取消。
- AI优先当前主线主力MS，保留少量精英与合法舰船、运输单位；不再为填满空位而预留低级单位预算。
- 驾驶员属性收益按本次要求提高；觉醒100起增加10个百分点命中与回避。普通攻击轮数为 round(武器基础轮数×机体机动/100×驾驶员机动系数)，至少1轮；驾驶员100机动为100%、200为125%。限次武器及格斗反击保持限制，舰毁强制脱出在此后向下折半，允许0轮。
- 修复东加拿大等战略局地战在临时构造水面舰艇／潜艇时误用平地、以及错误套用遭遇战舰船禁用标记的问题。实际落点仍校验真实地形、入口、占格和控制权，不改地图水陆数据。
- 共享每帧战斗状态与姿态计算，减少重复遍历，跳过画面外弹丸绘制；缩短轮换攻击间的空白。单位目录排序按本次排序缓存研究状态与最低COST，点击卡片保留列表和滚动位置。
- 弱网时在增量编码前合并积压快照，保持每个接收者独立，回执和聊天照常发送；不丢弃已经编码的增量帧。操作使用原请求ID重试，收到回执后只同步状态；新增自动重连及网络恢复后的立即重连。
- 补齐41条英／日文键，包含攻击计划、小队搭乘、部署和编辑器说明。未改用户自定义名字。

## 性能测量与边界

- 48单位、72条并行战斗演出：状态和姿态计算中位数约0.5ms，每帧72次姿态计算；画面外弹丸绘制0次。此数值不包含完整GPU绘制时间。
- 32单位AI寻路：中位数约1.85ms；格纳库出击决策约2.39ms。
- 48单位100次快照基准：完整JSON共2,960,982字节，增量JSON共51,528字节；压缩后分别226,549与15,969字节。增量协议原已存在，此处为现行回归测量，不表示全部节省均来自本次修改。
- 拥塞单测把连续101个待发状态合并成最后一个状态，解码序列连续，回执／聊天保留，快连接不等待慢连接。
- 本地模拟验证了延迟／丢失应用层响应、发送异常、拥塞及断线恢复；没有实测公网物理丢包率，也未覆盖所有手机GPU。

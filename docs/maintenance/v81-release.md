# V81 更新

- 机枪分类伤害倍率从0.75改为1，默认规则与项目配置同步。保留全武器共用0.75倍率，火神炮及近防武器的分类倍率保持0.75。相对于此前机枪伤害提升约33.3%，最终继续按25点取整；不修改原MOD武器基准或人工差值。
- 合入竖屏单位信息／小队栏的层级与避让修复，SFS头像栏移至小队栏上方，并修复暴露搭载单位的目标选择。
- 闪避朝向来袭敌人，结束后恢复锁定目标，机体与武器瞄准角一致。
- 减少逐单位画布尺寸查询、载具线性查找、重复骨骼采样；剔除屏幕外机体及爆炸特效。并行起播共享上一帧姿态快照，未到期／已结束的命中特效不再计算闪避坐标，复用已到达弹丸列表。
- 同一波自动交战仍并行起播，没有改变攻击／反击顺序及服务端裁定。

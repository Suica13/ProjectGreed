# V86 更新

- 普通菜单、常规战与快速战统一PMC名册、库存和ACE驾驶员；战略模式保留阵营差异及阵营音乐。
- 科技点作为累计进度，不再消费；按出战阵营标签比例分配PMC科技点，满额阵营退出分配。
- 部署许可价格为生产价格的3倍，购买赠送机体和默认套件各1份；机体和套件独立计数，每次生产一台，可选择出厂套件。快速战只检查许可，不消耗库存，货币和驾驶员经验按10%结算。
- 胜利基础资金、物资按本队开局人均编组COST使用整数阶梯公式，含驾驶员、套件及预先搭载单位。其他倍率和失败战果补贴保留。
- 战略科技开发1回合，单位生产按单台原生时间每20秒换算1回合，限制1～5回合，并接入套件生产。
- PMC驾驶员最高8级、ACE最高5级，更新累计经验需求与属性系数；ACE基础COST以25为步进映射至200～300。经验按击毁／自身机体COST比例计算。
- 增加驾驶员筛选及房间禁用设置。卡片紧凑、同列表等高，宽屏驾驶员双列；标题为名字、等级、阵营与年代，COST在技能行左侧，PMC标签为白色。
- 桌面编组及驾驶员名册双列、手机单列；载员卡片取消横向缩进和整行分隔，保留载机／格纳库说明。驾驶员按钮与其他操作按钮使用居中文本；招募状态统一位于头像下方，PMC驾驶员也标记已招募。
- 生产车间进一步收紧卡片高度，移除每次生产一台及已有许可的重复提示；未取得许可统一显示未许可。生产车间文字与头像顶部对齐；未开发始终显示红字“未开发”，已开发无许可显示红字“未许可”。生产与编组共用8标签上限及完整标签面板，COST不占数量。
- SFS本体1点并统计内部载员的容量：单MS共3点，双MS共5点且必须单独成队。合队、搭载、出库和HUD统计共用计算，嵌套在母舰中也生效。
- AI常规战／快速战禁用清单独立配置，默认禁止MS-06C。修复大扎姆及路维·捷露的光束伤害弹继承视觉辅助弹速度的问题。

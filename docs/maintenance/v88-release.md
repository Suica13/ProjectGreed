- 对战模式分为遭遇战模式（常规战、快速战）与战略模式（历史战役）；同步房间、提示与中英日显示。
- 0079E／0079L改为0079T1／0079T2，0087按科技树页划分0087T1／0087T2；共用机体采用最早年代，衍生形态继承年代。兼容旧存档年代禁用设置，同步导入规则。
- 单位卡片取消名称前的内部ID，搭乘单位保留序号。COST位于标签行最左侧，标签省略号可查看全部标签。
- 卡片使用按屏幕尺寸设置的固定高度。编组、图鉴与驾驶员在桌面完整显示至少8张，手机至少4张；生产车间保持单列，桌面至少6张，手机至少4张。
- 取消编组阵营PMC提示。搭载角标及载机／格纳库信息移到库存／套件行右侧；开发、许可和招募状态改为角标。载机预先搭载列表支持逐单位配置驾驶员。

- 修复驾驶员多语言技能／战绩重叠及手机详情按钮遮挡，增加头像与文字间距，战绩区取消底部额外空行。

# 战略局地战地图

43个区域保持原地图ID，地图由57×68缩小25%为43×51格，5v5。保留中心基地、六个据点、通往相邻区块的补给线与入口。入口方向由战略地图上相邻区块的方位决定。

移除继承自遭遇战的左右部署条带、部署扩展数据和对应人工陆地。防守方在己方中心基地或连接友军区域的入口部署；进攻方仅能从部队实际来路的入口部署。据点仍可占领和补给，但不额外生成部署区。

海洋地图的边缘入口与海上据点不再填地，中心基地设置一座小岛。地面部队需由运输单位搭载进入水面区域。单位创建时的临时排布不再要求改造地图地形；真实部署仍检查地形和占地。

北朝上，横纵采用相同投影比例，取景参考world.json区域边界及Natural Earth地形。陆地区域保留基地、据点与入口之间的可通行路径。人工平台、路径、投影范围及地形统计记录于地图geography字段。

生成需要临时numpy和shapely依赖，不加入游戏运行依赖：

```powershell
python tools/generate-campaign-maps.py --resize-existing --rebuild-geography --dependencies tmp/map-build-deps
npm.cmd run build
```

尺寸更新有版本标记，重复执行不会继续缩小。不带重建参数时保留已有地图。已经保存的局地战继续使用存档内地图和位置，避免强行缩放进行中的战局。

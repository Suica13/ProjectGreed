# 战场模式 / 雇佣兵战争模式

房间创建入口新增「战场模式 → 雇佣兵战争模式」。离线和联机复用相同的服务端裁定、动作去重、部署、攻击规划、应战及演出确认流程。机体及套件库存按实际阵亡逐次扣除，击坠、助攻与对局结束给予资金和物资；目前不发放科技点、驾驶员经验或活动击毁奖励。

## 地图和通用设施

首张地图为「战地 · 环峡高地」，只能用于雇佣兵战争模式。地图为72×48格：双层中央高地与外围环形平原、左右基地高地及西南／东北丘陵，由崖壁和可通行坡口区分；仅保留1、2、4、5号中立据点。采用地表 tilemap，地形、设施、初始部署区和据点都由 `assets/maps/battlefield/frontline.json` 配置。地图可配置每队多个主基地，双方都必须至少有一个。`tools/build-battlefield-map.cjs` 定向重建该地图与峡谷图集，并保留SL据点素材。房间只列出当前模式可用的地图；历史战役模式只显示剧本选择。固定阵营AI的选项位于独立的「雇佣兵战争模式设置」框体。

主基地、机枪炮塔、光束炮塔、导弹炮塔、加农炮炮塔、雷达分别保存在 `assets/units/Facility_*/unit.json`，可以由其他模式复用。设施使用正常单位的占地、HP、攻击、命中和视野规则，不能移动、组成小队或作为普通商品购买。雷达提供更大的视野与雷达范围，毁坏后失去该视野来源。

`tools/import-battlefield-facilities.py` 只读原 MOD 的 HQ、Turret Type A 配置及继承；复制本体/炮管贴图和音效，保留来源与原生载荷。HP 和单发载荷先按现有导入尺度减半，再应用全局换算。回合火力适配为机枪8发、光束2发、导弹4发、加农炮1发，之后沿用现行武器类型规则。当前主基地最终HP为300,000，四类炮塔均为20,000，调整通过人工差值与编辑审计事务保存，不改写来源HP。设施保留原 MOD 的完整主体、炮塔与炮管图层，按可见像素范围匹配占地：主基地3×3格，雷达1格、四类炮塔贴图为半格（逻辑占地仍为1格）。中立据点采用原 MOD SL（StrategicLocation）本体；占领后叠加对应队伍的蓝色或红色高光。来源清单由脚本生成到 `docs/imports/battlefield-facilities.json`，战斗数值查询以生成的 [现行规则](combat.md) 为准。

## 阵营 AI 与 PMC

两队阵营友军是独立固定控制者，不占可选玩家位置；每队6个位置标为1至6。内部0、1仍作为友军所有者以复用权威AI与回合系统，不显示为玩家槽位，也不能移除或手动控制。房主可选0079T1、0079T2、0087T1、0087T2及其阵营；PMC和普通AI在基地附近共享部署区，阵营友军免受PMC科技门槛限制。

阵营 AI 优先向附近未占领据点推进，之后向敌方主基地进攻，沿用正常的移动确认、武器选择、应战和战斗演出流程。设施使用同一套 AI 攻击流程。

## 占领和空投

非设施、非搭载中的可压制单位占地进入据点中心半径2圈的5×5方形区域时可自动占领。双方同时在范围内时保持现有归属。预览移动不触发占领，确认占领会清除移动撤销，避免撤回单位却保留据点收益。

## PMC维修与再次部署

开局带入的PMC编组构成本局调用名单；玩家只能申请自己的阵亡单位，不新增编组外兵力。单位及其脱出部件全部阵亡后开始维修，时间复用 `shared/economy.js` 的历史战役单机生产周期（每20秒一回合，按实际生产数量折算，限制1～5回合）。维修完成后，在自己的行动阶段点击己方据点或存活主基地，即可查看维修列表并申请部署；维修不额外收费，但申请部署需要扣除在场单位和已有部署申请后仍有可用机体库存（套件免费切换）；库存耗尽时不能再次部署。

申请后下一回合在所选据点的5×5方形区域或主基地半径4格控制区内选择合法空投位置，保持原套件、驾驶员和编组序号，恢复机体状态，以单机入场。落点被占满时保留申请，等待后续可用位置；地点失守或基地被摧毁时取消申请，可重新选择地点。每次再次被击毁仍扣除该次COST战力，并消耗1台机体库存；库存扣除以同一编组槽位的整机及脱出部件全部阵亡为准，保存结算标记避免读档或重复同步再次扣除；请求去重、所有权及回合限制由服务端校验，维修模板不公开给客户端。

## 战力和结束条件

双方按各自年代获得初始战力：0079T1为40,000，0079T2为60,000，0087T1为90,000，0087T2为120,000，最长100个现有回合行动阶段；上方计数器从0/100开始。回合上限及增援间隔由地图配置。

每回合结束时，据点数量较多的一方扣除敌方初始战力上限的1%，数量相同不扣除，领先多个据点也不叠加。0079T1每次扣除400；占领范围的外轮廓以队伍色标示，中立为灰色。

普通单位和炮塔等设施被击毁，只扣除一次该实体的最终COST（自定义驾驶员计入其COST）。主基地不额外按单位COST扣分；主基地累计损失的HP占该队所有初始主基地总HP的比例，乘以本队初始战力，再向下取整，作为额外战力损失。一次大伤害和分多次造成相同伤害扣分一致。

主基地不能主动维修，也不接受自动维修、补给光环等任何HP恢复。服务端保留每座基地的最低HP记录，重复同步或外部恢复不会使它重新增加。

任意一队全部主基地被摧毁或战力降到0即失败；双方同时满足则平局。第100次行动阶段结束时，剩余战力较少的一队失败，相同则平局。一般遭遇战的全灭判胜不覆盖此模式的基地和战力规则。

开局天气和时段、以及实际发生的后续变化，会由服务端同步记入双方战斗LOG。左上角标签只显示当前阶段，窄屏操作按钮在其右侧换行。

## 资金与物资收益

击坠敌方单位的玩家分别获得该单位最终COST的1/2资金和物资；参与过实际攻击的其他友方玩家各获得1/4。未造成伤害的攻击也计入助攻，不要求25%伤害贡献；同一玩家无论用多少单位攻击都只领取一次，击坠者不兼领助攻。友军攻击不计入，取消而未执行的攻击不计入。每笔金额向下取整，沿用服务器资金和物资奖励倍率，不套用快速战10%。

对局结束，0079T1队伍每名玩家固定获得基础2500资金、5000物资；0079T2为4000资金、8000物资。双方年代不同时按玩家所在队伍计算，胜负不改变此基础值，沿用服务器奖励倍率。阵亡库存与击坠奖励沿用唯一收据同步，结算固定收益每局只发放一次。


占领仅允许使用与历史战役相同的合资格地面单位：不能处于飞行、空中移动、搭载、移动预览或待执行计划状态；附近敌军仍会阻止占领。多人靠近时由最近的合资格单位执行，距离相同按单位ID稳定排序。执行压制的PMC玩家每次成功占领按所属队伍年代0079T1、0079T2、0087T1、0087T2分别获得500／1000、750／1500、1000／2000、1500／3000资金／物资基础奖励，沿用服务器活动倍率；阵营AI不领取PMC经济，同次占领重复同步不重复发奖。重新夺回失守据点视为新的占领。

科技点使用该年代与房间预算的独立1000至2000基数，0079T1之后每时代×1.25。平局基数，胜、负均×1.1；保留有效交战、阵营分配和活动倍率，最终四舍五入到25，见[经济规则](economy.md)。

## 设施重建、占格与额外奖励

主基地控制半径由2扩至4格；据点使用半径2圈、共5×5格的方形控制区。补给恢复、压制与再次部署使用对应控制区。主基地九格、据点中心格及所有设施占地均不可供其他单位站立或穿行。

主基地不重建。炮塔和雷达被摧毁后原地显示深灰色废墟，持续阻挡移动；第10回合到期恢复满耐久、EN、护盾，清除燃烧和部位损坏，同回合重复同步不重复重建。雷达基础耐久为7500。炮塔与雷达级别按年代为Lv1～Lv4；Lv1摧毁奖励400资金/800物资，每级增加200/400，助攻按该奖励的一半发放；重建后再次摧毁可以再次获得，活动倍率照常。

对每座敌方主基地，每位玩家分别累计其造成的实际耐久伤害。每达到该基地最大耐久的10%发放一次奖励，零伤害、护盾损失、友军伤害及溢出伤害不计。按基地所属0079T1、0079T2、0087T1、0087T2，单档奖励依次为500/1000、750/1500、1000/2000、1250/2500（资金/物资）；沿用活动倍率。

常规战与本模式在确认真实阵亡后立即扣除机体库存，重复同步或最终结算不再重复扣除；快速战仍免扣库存。战场再次部署列表显示剩余库存，库存不足时按钮显示“暂无库存”并禁用。ACE驾驶员在本模式不进入待回归状态，机体仍有可用库存即可继续维修和出击。

最终结算按整局全部阵亡次数显示损失数量与单位图标，包含同一编组槽位反复出击后产生的多次损失。

# 联络与商人

联邦任务按[1.4策划](../data/contacts/efsf-联邦联络人-1.4.json)开放29项，1～15项为0079T1，16～29项为0079T2。顺序交付后解锁下一项；初见授予联邦基础科技许可，后续任务覆盖两级全部联邦计划。科技奖励沿用计划对应单位许可，不直接增加科技点。吉翁、阿纳海姆及CE委托保留各自流程。

普通联邦委托通过合约模式完成，累计击坠任务不要求单局完成；仅人间地狱（阿巴瓦库）和权必有责（殖民卫星拦截）采用任务模式，接取后才能选择或开始；服务端校验所有参战人类玩家，观战者不领取进度。已完成关卡可重玩，原任务模式关卡暂时隐藏并停止新建。已交付旧任务保留；未交付旧任务进度重置到新目标。

两个特殊关卡不给资金、物资、机体、科技或驾驶员经验，普通合约沿用原结算。胜利结算只保存已接取任务的完成进度，回联络人交付才发奖励；重复回执和交付不重复发放。任务19按本次成功关卡的全队有效MS击坠数，每架1000资金交付。初稿待议金额沿用既有任务金额，新任务暂定15000+序号×1000；每项好感度100，800点升2级。明确的单位奖励及接取配发依初稿执行。苍白骑士沿用临时借用和回收规则。

联邦任务15或吉翁任务11解锁阿纳海姆；已完成阿纳海姆初见的旧存档继续可用。联邦第6项或吉翁第6项保留2级设施升级权限；完成「权必有责」或「余烬守望」后开放3级设施（信标除外），其他设施仍不能超过HQ等级。零件效果与年代见[战斗规则](combat.md)，0079T1沿用原任务门槛；0079T2配件按阿纳海姆六批委托分别开放购买，仍检查商人自身好感度；零件为持久库存，阿纳海姆同时检查对应任务和好感度。零件售价为稀有度×3000资金。

地图使用现有地形素材制作紧凑共享部署区。普通合约侦察需靠近仍存活目标三格内；资料回收在清除守军后使用回收交互，并按目标要求成功撤离；特定机体和套件检查实际击坠者。卡辛委托中伤及卡辛会使该事件失败；殖民卫星关卡限24回合清敌并接近三个控制点，阿尔比昂损毁判负。阿巴瓦库采用多批增援，坚持至18回合并撤离。详情见[任务地图说明](../design/efsf-missions.md)。

机库容量不足的配发及奖励进入保管库。任务、奖励、许可、库存和解锁状态按原事务保存。

联邦T2任务最低N3：16～18项N3、19～21项N4、22～25项N5、26～29项N6。「往昔时光」允许在宇宙合约跨局累计60台吉翁MS击坠；阿巴瓦库与殖民卫星特殊关卡分别使用13500和22500 COST编组额度。

## 资源兑换

阿纳海姆终端提供“资源兑换”服务，固定比例为1物资＝2资金，可双向兑换。输入兑换份数后显示交付和获得数量；每份交付1物资获得2资金，或交付2资金获得1物资。兑换不要求好感度或前置任务；对局中暂停兑换。余额不足、数量无效或保存失败时不改变资源；正常兑换以同一存档事务同时扣除和增加两种资源，不应用战斗或活动奖励倍率。

## 补给

联络的“补给”分页左侧选择扭蛋池，右侧显示封面、注目单位、代币余额、商品一览及单抽／十连按钮。0079年代补给代币是存档中的道具（兼容保留内部键`itemInventory.0079t1-token`），可从本池抽到。旧`itemInventory.supply-token`余额迁移到新道具，数量保留，不重新发放测试代币。卡片标明“0079年代扭蛋机”，仅消耗本池对应年代的代币。每抽消耗1枚，十连消耗10枚，各抽独立，无额外保底。奖级内按各类奖项配置权重分配，类内具体商品等概率；商品一览列出当前完整名单及总抽取概率。

抽取保存成功后播放米迪亚或胖叔叔运输机飞过、空投补给箱的演出，补给箱落地后点击开箱，弹出本次全部奖励及机体／零件／资源图标。飞行、落地、开箱和奖励揭晓分别播放音效，遵守音效音量设置。关闭、刷新或离开页面不再次抽奖、不回滚已保存奖励；关闭演出后仍可在分页查看本次结果。封面的4号机持光束步枪朝左、5号机持火箭筒朝右，使用现有射击关键帧；仅改变展示，不改变奖励默认套件与战斗规则。

补给分页本体与右侧展示区固定，仅左侧扭蛋卡片列表可滚动；奖励和商品弹窗独立滚动。关闭演出后可点击“查看上次补给”重新打开本次奖励面板，不再次扣币或播放运输动画。

小菜一碟（efsf-11）以前置往事速递（efsf-9）解锁；财不外露（efsf-12）同时要求掠地攻城（efsf-7）和小菜一碟已交付。财不外露按精灵高达及目标栏采用敌军联邦，纠正策划条件行写吉翁的冲突。只接入这两项新委托，1.3 JSON内其余新增策划暂不实现。

## CE0071T1联络人

交付“小菜一碟”或“不可退让”后解锁地球联合军与扎夫特，完成各自初见演出后获取基础科技和军队重建／重装规格金恩计划许可。两方分别有10项连续委托，N2～N6每级两项，在第10项交付后完成全部T1科技许可解锁。后期多目标行动要求同一局完成全部子目标并成功撤离，清剿仅累计成功撤离合约的战果。详见[完整对白、任务表与旧存档兼容](../design/ce-contact.md)。

联络人卡片统一尺寸、缩小并分置于UC／CE两个框体，已解锁卡片显示好感度／等级，未解锁卡片仅显示“未解锁”，不显示前提条件；桌面左右排列，手机上下排列，联络人列表不提供滚动条。

联络人累计好感度读取与保存时，不低于其已交付任务的好感度总和。旧存档字段缺失或归零时按已交付记录补回，保留更高的已有好感度，不重复发放资金、许可或其他任务奖励。

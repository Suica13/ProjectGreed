# 联络与商人

联络分为任务与商人两个页面，有地球联邦军联络人和阿纳海姆。点击头像打开终端。联邦联络人提供连续委托，阿纳海姆出售零件。联邦联络人好感度不足800点为1级，达到800点为2级，卡片与终端同步显示；尚未设置更高等级。每次交付联邦任务增加100好感度，好感度独立随存档保存。

联络任务是独立的委托系统，与合作模式的剧本关卡无关。首次完成“初见联络人”通信后，直接授予反MS计划中的机体许可，不累计科技点，也不改写科技树开发进度。后续“解锁科技”均指直接获取对应计划的单位许可。通信中关闭不会提前授予许可，下次打开可重看；完整通信只奖励一次。

任务按顺序接取、完成后交付，随后开放下一项。联络的任务分页左侧按联络人分组，组名下排列已接取任务卡片；选择卡片后，右侧固定区域显示任务内容、目标和奖励，可直接交付。商人终端沿用相同的分组卡片与详情布局，并显示该联络人的全部委托。条件与目标拆为两行，例如“合约模式 · N1以上 · 0079T1 · 敌军：吉翁军”和“歼灭吉翁军MS 0/6”；地面委托另列地面条件，进度紧随目标文本。战斗内任务列表沿用该信息格式。任务进度由服务端按进入合约时的已接受任务记录裁定，结算回执写入本地，交付时一次性领取奖励和好感度。重连和重复结算／交付不会重复发放。旧版错误关联的剧本任务记录仍会清理。

联络人标题为展开／收起按钮，下方任务卡片缩进排列；未解锁任务暗色但可以点击查看，接受任务按钮保持禁用。未选择任务时，右侧固定填满详情区域并显示“请选择任务”。终端固定填充可用区域，任务列表和详情分别滚动；奖励按货币与好感度、单位、科技分行，初始装备单列于任务奖励之前。联络演出采用上方居中头像与下方对话框，每条新台词播放一次信息音，刷新同一台词不重复播放。

任务卡片和详情标题只显示任务名，不显示序号。解锁科技树中间主线节点的委托及其全部前置委托归为主线，其余委托在名称前显示“支线”标签；当前支线为掠地攻城、艺术就是爆炸。未解锁委托在“接受任务”按钮右侧列出尚未交付的前提任务或尚未完成的初见通信条件。点击卡片只替换右侧详情，保留左侧列表、焦点和滚动位置；重复点击当前任务不重置详情，余额或语言刷新时保留两侧当前滚动位置。

委托策划版本为[1.21](../data/contacts/efsf-联邦联络人-1.21.json)。全部任务各增加100好感度，达到800点为2级。旧存档已交付任务按每项100点一次性补足原有0.1点贡献，保留其他好感度；迁移版本随存档保存，不重复增加。第1～6项按顺序交付，第7、8项分别由第6项解锁，第9项需要第8项，第10项需要第9项。N4～N6现已开放，第10项可在满足前置委托后正常完成。

任何参战玩家接取符合房间条件的事件委托，都会在共享合约地图上生成一次该事件；没有接任务的玩家也能共同完成事件，但只向接取者保存任务进度。回收任务及往事速递要求接取者有存活单位成功撤离。首秀与最好的差事按全队实际击坠的吉翁MS去重计数；艺术就是爆炸额外检查实际击坠武器为炮击技能；武力说服按工厂最后击坠者是否为苍白骑士系单位判断。特殊委托事件不重复发放普通合约事件收益。往事速递的基地配备1座HQ、12台驻守MS和4座机枪炮塔；驻守MS适用年代、阵营和环境限制，并沿用多人兵力缩放。

苍白骑士不额外增加补领商店；即使没有生产许可，任务赠送机体仍可按原规则维修和大破复原。任务借用机体不可出售、销毁或从保管库移除，界面禁用相应按钮，存档操作也会拦截。完成武力说服的4座工厂目标后，在结算事务中自动卸下全部零件、解除驾驶员配属，再回收赠送的苍白骑士1台，包含大破机体或仍在保管库的机体；零件库存和宿舍驾驶员保留。新接取委托使用借用标记追踪机体。旧版已接取或可交付记录没有标记时，识别并保护至多1台同型机；已交付记录不追溯回收。第6项交付后的设施升级费用见[基地设施](base-facilities.md)。

机库的“保管库”位于单位／舰船库存数量左侧。活动、任务或结算奖励超出对应机库容量时，单位进入待领取队列，不丢弃。打开后按单位卡片右侧的“接受”逐台入库；相应机库满员时按钮禁用。保管库不占可出击库存，不能直接编组；领取与库存变更在同一存档事务内保存。

商人仅出售零件，不出售单位。零件表共实现33种，22号光束扰乱膜散布装置和29号爆炸反应装甲暂不制作。阿纳海姆与地球联邦军按各零件配置出售，指定联络人好感度等级不足时可查看但不能购买；各联络人独立计算等级，达到800点为2级。吉翁公国军联络人暂未开放，其来源零件已实现但不在其他商店代售。年代只作标签，不限制购买。每件售价为稀有度×3000资金（1／2／3星分别为3000／6000／9000），不消耗物资。零件为可重复购买的实物：`pluginInventory`记录持有总数，减去机库、舰船及待入库记录中的已装配数量即为可用数。装配、更换必须拥有空闲零件，同机同种不可重复；拆卸或出售／销毁机体后零件恢复可用。大破机体保留零件，修复不重复收费。旧存档没有零件库存字段时，按已装配数量迁移，未装配零件不免费赠送。原18个零件ID保留，新名称及效果直接更新，已持有数量与装配位置不丢失。

基地的仓库子页以物品格子展示已持有零件，图标右下角标注持有总数。选中格子后显示名称、稀有度、COST、效果及持有／可用／已装配数量，数据直接来自同一库存，不额外占格或限制数量。“材料”分页暂未开放。

资金、库存和装配通过Economy同一存档事务保存，写入失败时回滚；更换零件仍保留原耐久与EN比例，对局中暂停购买。详情见[战斗规则](combat.md)的单位零件章节。

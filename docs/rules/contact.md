# 联络与商人

联络分为任务与商人两个页面，有地球联邦军联络人和阿纳海姆。点击头像打开终端。联邦联络人提供连续委托，阿纳海姆出售零件。当前等级固定1；每次交付联邦任务增加0.1好感度。

联络任务是独立的委托系统，与合作模式的剧本关卡无关。首次完成“初见联络人”通信后，直接授予反MS计划中的机体许可，不累计科技点，也不改写科技树开发进度。后续“解锁科技”均指直接获取对应计划的单位许可。通信中关闭不会提前授予许可，下次打开可重看；完整通信只奖励一次。

任务按顺序接取、完成后交付，随后开放下一项。已接受任务显示在联络的任务列表中；内容、目标、进度和奖励在终端左右分栏显示。任务进度由服务端按进入合约时的已接受任务记录裁定，结算回执写入本地，交付时一次性领取奖励和好感度。重连和重复结算／交付不会重复发放。旧版错误关联的剧本任务记录仍会清理。

未解锁任务暗色且不可点击。终端固定填充可用区域，任务列表和详情分别滚动；奖励按货币与好感度、单位、科技分行，初始装备单列于任务奖励之前。联络演出采用上方居中头像与下方对话框，每条新台词播放一次信息音，刷新同一台词不重复播放。

所有任务各增加0.1好感度。任何参战玩家接取符合房间条件的事件委托，都会在共享合约地图上生成一次该事件；没有接任务的玩家也能共同完成事件，但只向接取者保存任务进度。回收任务还要求该玩家有存活单位成功撤离。首秀按全队实际击坠的吉翁MS去重计数；武力说服按工厂最后击坠者是否为苍白骑士系单位判断。特殊委托事件不重复发放普通合约事件收益。

苍白骑士不额外增加补领商店；即使没有生产许可，任务赠送机体仍可按原规则维修和大破复原。第6项交付后的设施升级费用见[基地设施](base-facilities.md)。

机库的“保管库”位于单位／舰船库存数量左侧。活动、任务或结算奖励超出对应机库容量时，单位进入待领取队列，不丢弃。打开后按单位卡片右侧的“接受”逐台入库；相应机库满员时按钮禁用。保管库不占可出击库存，不能直接编组；领取与库存变更在同一存档事务内保存。

商人仅出售零件，不出售单位。所有18种零件仅由阿纳海姆出售，地球联邦军不出售零件。每件售价为稀有度×3000资金（1／2／3星分别为3000／6000／9000），不消耗物资。零件为可重复购买的实物：`pluginInventory`记录持有总数，减去机库、舰船及待入库记录中的已装配数量即为可用数。装配、更换必须拥有空闲零件，同机同种不可重复；拆卸或出售／销毁机体后零件恢复可用。大破机体保留零件，修复不重复收费。旧存档没有零件库存字段时，按已装配数量迁移，未装配零件不免费赠送。

基地的仓库子页以物品格子展示已持有零件，图标右下角标注持有总数。选中格子后显示名称、稀有度、COST、效果及持有／可用／已装配数量，数据直接来自同一库存，不额外占格或限制数量。“材料”分页暂未开放。

资金、库存和装配通过Economy同一存档事务保存，写入失败时回滚；更换零件仍保留原耐久与EN比例，对局中暂停购买。详情见[战斗规则](combat.md)的单位零件章节。

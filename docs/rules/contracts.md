# 合约模式

以单张大地图进行的合作PVE，替代原战场扫荡的路线、BOSS和休息区流程。联络页商人任务与本模式相互独立。为兼容既有房间设置，网络模式字段暂沿用 `sweep`，运行状态使用 `game.contract`。

## 房间与部署

0079、0087及CE0071均开放地面和宇宙合约，难度统一为N1～N10，舰船上限为5。0079、0087各自合并T1/T2年代：N1～N5使用T1敌军，N6～N10的T2抽取权重依次为20%、40%、60%、80%、100%。CE0071使用现有T1单位逐级提高质量。难度固定玩家编组COST，不能通过自定义房间预算覆盖。

单人初始敌军数量依次为9、12、18、24、30、30、30、30、30、33；多人及武装介入保留各自倍率。

宇宙兵力池在 `shared/contract-forces.js` 根据当前单位目录生成，按年代、阵营、AI科技许可、禁用清单和宇宙适性至少100筛选，排除专属驾驶员机、未完成机体、纯形态、设施及普通运输单位。每次抽取完整三机编队；按机体最低COST划分质量梯度，MA权重为常规机体的十分之一。宇宙追击运输波选择对应阵营与年代的宇宙舰船，搭载单位仍来自宇宙兵力池。事件预算沿用同年代地面预算；0087沿用0079联邦的同级事件预算。

最多5位PMC玩家协作，玩家可使用不晚于房间年代的单位，敌军只使用所选年代与阵营的环境适应单位。每局由服务端生成新的地形、目标位置、两个边缘入场区和两个边缘撤离区；两个入场区位于相对的两条随机边缘，全队均可在任一区域部署。两个撤离区分布在另外两条边缘，并避开入场区及彼此。地面每局确定一个随机主题：草原、雪地、沙漠或城市，使用对应的TileMap图集与绘制调色板；雪地、沙漠同时使用对应逻辑地块，城市生成三格宽街道与废墟街区。森林、丘陵、岩石和水域按主题组合，水面有深浅蓝色、水纹及与实际陆格相接的岸线。主题保存在地图布局快照中，全员一致，旧战局缺少主题时回退为草原。宇宙保留大片空域并生成散布的小行星和残骸。宽通道连接入场区、事件目标与两个撤离区，避免大型舰船被随机地形封锁。

每个部署区按舰船上限采用14×11／16×12格，两个区域全队共享；每个撤离区为6×6格。房间预览随环境显示地面或宇宙固定封面，仅作环境示意，实际地形仍在每局开始时随机生成。

地图与区域由服务端快照同步，客户端使用已有TileMap图集绘制，分块缓存不因地图增大而取消。上方“入场区1”“入场区2”“撤离区1”“撤离区2”按钮用于定位，作战简报分别标出各个区域。旧存档仍可沿用单个入场区。

编组COST以0079T1为基准，0079T2乘1.5，0087T1、0087T2、0093T1在T2倍率基础上依次再乘1.25。先按原年代预算四舍五入到500的倍数，再统一提高50%，不逐年代累计取整；此提升仅影响玩家编组上限。各年代N1依次为3000／4500／6000／6750／9000C。0079T2的N1～N6为4500／6750／9000／13500／18000／22500C。CE0071T1使用初始基准。舰船数量上限不随年代变化。事件数量等于N级，地图尺寸随难度扩大；0087及0093仍暂未开放选择。

0079敌军仅可选联邦／吉翁；0087仅可选奥古／提坦斯／新吉翁；0093与CE使用各自对应阵营，且仍需存在当前年代的可用单位。

“指定阵营”按“敌军[我军]”显示并保存两个独立阵营，例如“吉翁公国军[地球联邦军]”。括号内指定事件友军的选兵阵营，玩家仍使用PMC编组；双方必须属于所选年代且不能相同。0087可组成三方阵营间的六种有向配对，不再根据敌军自动猜测友军。旧设置未保存我军阵营时回退到该年代的另一个有效阵营。年代开放限制保持不变。

AI随机选兵仅允许科技树可解锁的单位（明确配置的事件单位除外），并排除MS-06C，包含合约事件驻军、巡逻及增援池；玩家持有和出击不受此禁选影响。

敌军仅从当前环境适应性达到100%的单位中抽取：宇宙要求宇宙适应性100%，地面要求地面或空中适应性100%。此限制同时用于初始部队、事件驻军、巡逻队和增援乘员。运输单位随地面／宇宙切换。

### 0079T1地面编队池

联邦和吉翁N1～N6分别使用[联邦部队池](../design/contract-force-pools-efsf-0079t1.md)和[吉翁部队池](../design/contract-force-pools-zeon-0079t1.md)。构建时由`tools/compile-contract-force-pools.cjs`将两份MD转换为`shared/contract-force-pools.json`，服务端和独立HTML共用同一配置；修改后执行构建，运行中的服务端需重启。

联邦从61式A5和飞机、陆战型吉姆过渡至吉姆主力；N4开始出现吉姆，N6允许钢加农三机、钢坦克三机和高达／钢加农／钢坦克混编。吉翁前期扎古、中期老虎、后期大魔，N3起不再出现常规坦克和战斗飞机编队。常规池不使用支线单位。

编队抽取权重：主力／常规8，常规辅助或部分4，少数1，极少数0.25；N5、N6的少数与极少数再乘1.15。先在剩余预算、容量与增援空位允许的完整编队中抽取，再为各机随机选择可用套件。权重与预算系数独立；吉姆狙击型三机混编预算250，扎古狙击型六机混编450。战蟹当前地面适应性90%，不满足既有100%环境筛选，含战蟹的编队暂不参与陆地抽取，配置仍保留。

普通事件驻军与特殊增援采用MD的本级预算。本轮N1～N6预算分别约保留原值的50%／60%／65%／70%／70%／75%，取整到25且不低于75，MD正文已是减量后的值，运行时不再重复减量；每四个完整己方回合的边缘巡逻使用本级“工厂被毁增援”预算。初始巡逻批数仍为`1＋floor((难度－1)/3)`，不再叠加旧AI席位随机初始部队。防守友军据点无初始敌军，联络委托明确指定的目标与驻军保留原脚本。

明确预算替代旧的110%基础人数与75%增援人数换算，每波乘`1＋0.25×(玩家数－1)`，N3至N6再分别乘1.10／1.15／1.15／1.15，最终取整至25，1～5人为1／1.25／1.5／1.75／2倍。预算不足不拆编队、不透支、不累计。运输追击按指定运输机数量，逐艘以各自载员预算抽取完整可搭载编队，受实际容量和全局增援上限约束，不生成空运输机。后续通用人数与阶段选兵说明仅适用于未配置独立编队池的年代。

### 其他年代保留的阶段选兵规则

0079T2仍按所选阵营及年代划分前期／后期，不跨年代取单位。以第4项付费主线科技为分界，联邦对应吉姆改开发计划。分界科技及其后的解锁门槛归后期，其前归前期。同机体的不同套件共用阶段，COST不决定科技阶段。

| 难度 | 敌军战斗单位抽取比例 |
| --- | --- |
| N1～N3 | 前期100% |
| N4～N6 | 后期100% |

先按难度选择前／后期，再抽机体和武器套件，避免套件较多的机体过度出现；小队内可使用相同机体。初始战斗部队、事件驻军、巡逻、空降及运输机乘员共用此规则。筛选后某个阶段没有适应该环境的单位时，回退到同年代、阵营、环境的另一阶段，不跨年代补齐。用于入场的固定运输机、事件工厂与联络任务指定目标保持原配置。

0079T1地面不再使用旧的MS65／坦克25／飞机10通用权重，统一按前述独立编队池抽取。

合约模式强制完全战争迷雾并启用驾驶员，由服务端统一覆盖。编组限制区域显示当前难度和年代对应的COST及舰船上限，规则预设固定显示“合约模式”。

机动敌军数量在旧基准上提高10%，按实际参战玩家数乘以 `1.1×(1+0.25×(玩家数−1))`：1／2／3／4／5人分别为1.1／1.375／1.65／1.925／2.2倍。初始部队与事件驻军累计取整，后续增援另行累计并应用75%兵力规则，避免小批次独立取整造成偏差。敌军AI席位不再各自额外叠加一份初始兵力；观战者不计入人数。工厂等固定任务设施数量不变。

N5、N6普通敌军驾驶员的老兵与精英相对一般驾驶员权重各提高15%；归一化后，N5一般／老兵／精英约72.29%／22.17%／5.54%，N6约56.60%／32.55%／10.85%。N1至N4保持一般驾驶员，剧情指定驾驶员优先。

## 大地图事件

“救援失联小队”已移除。恢复旧对局时会清理残留的该事件、对应演出提示及救援NPC，结算按剩余普通事件数量计算完成比例；“防守友军据点”保留。

N1起即可抽取全部七种事件；先抽取不同类型，事件超过七项时允许同类事件再次出现。地图使用不同几何标记区分资料、歼灭、工厂、据点、盾形防守、箭头上传和雷达站。事件总数仍等于N级，不会因事件池扩充而额外增加。

- **回收战场资料**：白色3×3范围。己方可行动单位任一占地进入范围后，行动栏原“占领”位置显示“回收”。确认消耗本次行动、范围变绿并立即完成；地图边缘随后出现配置数量的运输单位，按本级载员预算搭载完整编队，向事件位置追击。0079T1地面N1～N6分别配置1／1／2／1／2／2艘运输机；地面使用米迪亚／胖叔叔，宇宙使用哥伦布／巴布亚。
- **消灭小股敌人势力**：事件附近驻守部队为目标，必须全部消灭。目标进入己方视野后才在头顶显示红色倒三角“目标”标记；文本随语言切换，几何尺寸适配文本宽度。
- **破坏敌方工厂**：N1～N4有两座，N5～N6三座。每座耐久为`20000＋5000×(难度－1)`，即N1为20000、N6为45000。遭到攻击会召集附近巡逻队；每座被毁时从边缘新增一队援军，以三机为减量前基准，同一座工厂不会重复触发。全部击毁才完成事件。
- **占领敌方据点**：沿用雇佣兵战争据点图形和5×5红色覆盖区（中心据点格不可站立），己方单位进入后自动启动。下方五个方块每个完整己方回合将一格由红变蓝；失去己方控制或敌军进入时暂停，保留已完成进度。五格完成后范围变绿。启动后附近巡逻队前来调查；每四个完整己方回合从边缘增援，启动后的第三个己方回合额外空降防守部队。N1～N3每次一队、N4～N6两队，以每队三机为减量前基准，统一应用下述增援数量规则。启动当回合不计入进度，重复快照不会推进。
- **防守友军据点**：PMC单位进入以据点为中心的5×5方形覆盖范围（含四角）启动。初始有一个核心、两座机枪炮塔和两个自动防守的友军MS小队，每队三台，不生成该事件的敌方驻军，也不在覆盖区内放置初始敌军。友军阵营取房间组合括号内的阵营。保护核心五个完整己方回合即可完成。核心耐久为`40000＋5000×(难度－1)`；启动时及经过两、四回合时有敌方攻击波。核心被毁仅使本事件失败，不直接结束整场合约。
- **上传战场数据**：进入蓝色3×3区域启动，保持有PMC且无敌军三回合，离开或敌军入侵时暂停，保留进度。启动时引来一批增援。
- **摧毁敌方雷达站**：实际生成一座可摧毁雷达设施，耐久沿用同难度工厂。靠近或受击时开始，召唤一次敌军响应；摧毁设施完成。

防守友军使用本年代、对应环境的合作阵营机体，保留驾驶员与正常战斗规则，由独立AI席位控制，不占五名玩家席位。未靠近激活前原地待命，敌方AI不会因这些待命友军提前启动战斗。激活后仅就近防守，不追击远处敌人。友军不会替玩家启动其他占领／上传目标，不进入玩家编组、库存损失、撤离等待或PMC全灭统计。事件失败显示独立CUTIN与灰色地图标记，不提供该项收益；仍可继续其他目标或提前撤离。所有新事件的增援同样受多人缩放、75%数量规则及全局存活上限约束。

除防守友军据点外，每项普通事件基础驻守`3＋floor((难度－1)/3)`台单位，仅在没有独立MD部队池时，经110%基础兵力、本级减量系数及多人倍率累计取整；平时在事件附近五格内巡逻。事件开始、遭到攻击或本编队传感器发现敌人后进入警戒／交战状态。初始敌方编队及额外`1＋floor((难度－1)/3)`个三机巡逻队在地图上随机巡逻，各自使用本编队的视野与雷达，关闭战争迷雾也不赋予远距离全图警戒。附近巡逻队接到事件或受袭支援信号后前往现场，不等待全军集合；驻守部队只响应所属事件的信号，不会被其他事件激活、回收或受袭引走。驻军自身受袭或发现玩家时仍可正常交战。巡逻路线、警戒和伤害历史仅存在服务端，不进入公开快照。

每四个完整己方回合从地图边缘新增巡逻队，沿用环境筛选。使用独立MD部队池时按减量后的预算抽取完整编队，叠加多人倍率及N3至N6难度兵力倍率。未配置独立部队池的年代，N1～N6再乘50%／60%／65%／70%／70%／75%的兵力系数；初始兵力与驻军还乘110%及多人倍率，后续增援再乘75%，按累计数量四舍五入后逐波分配；普通增援按每队最多三台组织，兼容单位通过共用小队规则合并到同一格，不等待全军集合；大型、环境或容量不兼容的单位独立行动。每个小队独立使用本队传感器，入场后先巡逻或前往事件地点调查，支援信号不会直接暴露玩家位置；发现玩家才追踪，丢失接触后调查最后已知位置再恢复巡逻。所有事件完成或当前敌军全灭后仍会刷新，直到玩家撤离或全灭。重复快照不会重复刷新。移动、攻击和乘员出击继续经过共用规则裁定。歼灭当前敌人不会直接结束合约，整批攻击裁定同样交由合约撤离条件决定胜负。所有交互请求仍校验唯一ID、战局、revision、回合、权限、距离和单位状态，重复请求不能重复完成事件或结算。

敌军质量随N级提高，在既定年代、前后期和环境范围内，优先抽取高COST机型。按机型最昂贵套件的COST计算相对权重：最低为1，最高为N＋2；先选机型再随机套件，避免套件多的机型额外占据概率，保持多样性。高COST质量权重以非MA机型的COST范围为参照，避免大型MA拉低普通MS的质量差异。若当前候选池同时有MA与其他机体，MA机型权重降至原权重的25%，且合计抽取概率最高10%；仅有MA候选时保留可用性，剧本指定单位不受影响。N1～N4的普通初始敌军、驻军、巡逻、事件增援、运输机及载员使用一般驾驶员；N5每名驾驶员独立抽取：一般75%、老兵20%、精英5%，N6为一般60%、老兵30%、精英10%，不随机生成ACE。抽取由服务端依据战局种子与单位序号确定，重连不会重抽；联络剧情明确指定的驾驶员等级优先。独立MD部队池中的多小队大编队及高预算稀有机权重已下调，N6高达改为极少数。敌军机体与武器数值沿用共用配置。

已撤离玩家和单位不再参与行动检测、应战、共享应战方案确认及演出等待；剩余玩家确认结束计划后，继续按正常的队友／友军AI、应战和演出流程推进，不等待已经撤离的玩家确认。仍在地图上的人类玩家保留手动结束行动的规则。

席位无人接管或玩家断线且有在线队友时，其单位临时共享给队友，保留原所有权；队友可以操控、应战及从撤离区代为撤离。无人席位不加入结束计划、应战确认和演出等待名单。最后一名在线队友结束计划时，无人席位尚未行动的单位进入待机，避免卡住回合。原玩家重连或席位被接管后恢复房间原有共享规则；观战者与敌方玩家不能接管这些单位。

## 增援存活上限

初始敌军、事件驻军、联络委托目标和步行／空降增援均尽量组成最多三台的实际地图小队，沿用控制权、地形、飞行状态与六容量点规则；不同事件的驻军不混编。“硝烟野餐”的六台目标MS组成两个三机小队，每队两台扎古ⅡF型与一台扎古ⅡS型，仍逐台计算击破进度。随机兵力每三台采用同一机型套件，减少无法合队的混搭；大型或不兼容单位独立行动。

N1～N6的巡逻增援同时存活上限依次为12、15、18、21、24、27台；按全地图计算，与镜头位置、迷雾揭露或玩家人数无关。周期巡逻、工厂被毁增援、据点增援、空降和回收追击共用此上限；运输机及其存活乘员分别计数。初始部队、初始巡逻队和事件驻军不占用该增援额度。上限已满时跳过当次刷新，不累计待补发波次；发生损失后在下次正常触发时恢复，剩余空位不足以容纳完整编队时跳过，等待足够空位，不拆分补兵。运输增援至少需要两个空位，避免生成空运输机。上限不会阻止事件本身完成。

## 事件提示

进入部署阶段时，任务模式和合约模式统一显示作战简报并播放一次提示音。简报预览实际地图，雷达光带自上而下扫描；每4.5秒依次选中一个目标，在地图上高亮并展示说明，也可以手动点选。右下角关闭后继续部署，目标面板内的“作战简报”可重新打开；同步快照和同一客户端重连不重复自动展开。简报是本地展示，不参与联机确认或阻塞其他玩家；剧情对话开始时自动收起。每个事件由服务端发送有序的开始／完成CUTIN，回收会依次播放开始和完成。歼灭／工厂事件在靠近目标或驻守部队／目标受击时开始，据点进入覆盖区时开始。最后一项事件完成CUTIN之后，额外播放一次“已完成所有目标”。提示自动退场、不要求全员确认，不阻塞服务器或让观战者影响进度；中途新加入不补播历史CUTIN。封面使用地面／宇宙两张扁平几何矢量图。

## 撤离与收益

地图边缘生成两个撤离区，不需要呼叫或等待倒计时；单位中心进入任意一个区域即可撤离，无须全舰体进入。选中自己已到达区域的单位，右下角行动栏显示闪烁的“撤离”按钮；点击只撤走该单位，运输单位携带的全部乘员一起撤离。待机后仍可撤离，但有未确认移动或攻击计划时不能撤离。队友不能代替撤走其他玩家的单位。旧存档仍可沿用单个撤离区。

撤离单位离开地图但保持存活，耐久、EN与部位状态冻结，不参与后续攻击、索敌、补给或回合扣费。个人部队撤完后显示等待队友提示，不提前写入存档；已无场上单位的玩家不阻塞回合或演出，即使断线也不影响队友。所有存活部队都撤走后统一结算；若没有任何单位成功撤离且全军覆灭，则失败结算。已有单位安全离场、剩余部队战死时，保留安全撤离单位并正常结算。

## 武装介入

指定阵营提供“武装介入”（网络参数`sweepFaction: "NONE"`）。按所选年代生成所有可用敌方阵营：0079为联邦／吉翁，0087为奥古／提坦斯／新吉翁，0093为对应0093联邦／新吉翁。每阵营独立队伍、视野、小队、搭载关系和攻击判定，互为敌人；依次使用红、橘红、粉红。玩家仍组成PMC合作队。敌方阵营共享NPC行动阶段，每个单位每阶段只行动一次，避免阵营增加导致回合收益频率改变。

普通事件分配所属敌方阵营，驻军和事件增援沿用该阵营的部队池，巡逻队优先围绕本阵营事件点活动。武装介入不生成防守友军据点事件。巡逻队为全敌方共用的一条刷新流，并非每个阵营各刷一套；累计每十次正常巡逻刷新增加一次，初始兵力额外提高25%，排除事件单位后的机动敌军存活上限为本局初始兵力×1.5向下取整。普通事件数量在N级基础上加1，地图宽、高各乘1.1并向上取整；资金、物资、科技点和驾驶员经验额外乘1.25，与全局合约奖励乘1.25叠加，在难度奖励增幅之外的叠加倍率为1.5625。多人增幅仍统一应用一次。

敌军相互击毁不计玩家击杀、击杀委托、助攻经验或过程奖励；歼灭／破坏事件若有目标被敌军击毁则标记失败，不发放该事件收益及委托完成进度，防止敌人代打获利。需要玩家最后一击的单位／零件试验读取服务端击毁记录。回收、上传和撤离仍要求玩家实际参与。

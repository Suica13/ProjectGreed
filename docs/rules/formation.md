# 舰船与格纳库编组

常规编组使用编组总 COST 和舰船数量两项限制，舰船数量统一为 **3 艘**，计入作为编组根单位的战舰与运输机。舰船、乘员和驾驶员共用总 COST 预算，不再限制全编队的单位容量点；各格纳库内部的容量、类型限制、嵌套搭载规则和战场小队容量保持不变。

编组界面先选择战舰或运输机，再从各格纳库卡片的“＋”配置预先搭载。无格纳库战舰可独立入场；普通单位必须预先搭载。旧编组可以保留编辑，但超过三艘或母舰无法出击时，对应舰船及其乘员同步停用。

快速战可选择常规编组或自由编组。自由编组保留总单位容量点、独立单位入场、单机 COST 上限与玩家比例设置。其他玩家模式采用常规编组。历史战役剧本部队、扫荡敌军及雇佣兵战争的独立阵营友军保留专用生成规则。

普通 AI 的常规编组同样由服务器按最多三艘筛选；生成器内部候选单位预算与玩家舰船数量独立，避免只生成三个单位而漏掉载员。

扫荡补员仍检查总 COST、三艘舰船和各格纳库的实际容量。房间九档预设为1500、2500、5000、7500、10000、12500、15000、17500、20000 COST，常规编组均最多三艘；切换自由编组时恢复原容量点设置。

新存档编组为米迪亚搭载三台扎尼、胖叔叔搭载三台默认机枪套件扎古2F。当前基础编队总 COST 为1100、两艘运输机。赠送五套：运输机各五台、两类MS各十五台；已有存档不补发。收益见[经济规则](economy.md)。

编组分享使用PGF1代码，保存机体、武器套件、预先搭载关系和常规／自由编组类型，不包含个人驾驶员资料、库存或部署许可。旧代码继续兼容：存在独立普通单位时推断为自由编组，否则使用常规编组。主菜单导入时切换对应编辑视图；房间内导入仍服从房间的编组规则及上限。导入只增加编组模板，不发放库存或许可。保存失败时保留本次会话中的编组并明确提示，不显示已保存。

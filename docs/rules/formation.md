# 舰船与格纳库编组

常规编组的房间设置只保留编组 COST 上限与单位容量点上限，默认为 **1500 COST／18点**。舰船、运输机、搭载单位及驾驶员共同占用一个 COST 预算；不设置单机 COST、舰队独立预算或战舰四分之一价格上限。

容量点沿用原权重：战舰4点、MS 2点、其他单位1点。舰船与所有乘员分别计入总容量点，同时保留各格纳库的内部容量、类型限制与嵌套搭载规则。驾驶员 COST 计入总预算，不额外占容量点。

编组界面先选择战舰或运输机，再从各格纳库卡片的“＋”入口配置预先搭载。无格纳库战舰可独立入场；普通单位必须预先搭载。旧编组未搭载单位可保留编辑，但不能独立绕过格纳库入场。母舰无法出击时，乘员同步停用；超预算或容量时从编组列表筛选合法出战部队。

AI的科技、生成、出兵及既有数值不调整。普通AI原有默认36点容量及250单机 COST 使用兼容配置保留，避免玩家默认18点意外改变AI。历史战役的剧本部队沿用现有规则。

扫荡中已合法入场的存活单位可继续进入后续节点；补入的新普通单位须选择格纳库。房间九档预设为1500、2500、5000、7500、10000、12500、15000、17500、20000 COST，容量均18点。

快速战可选择常规编组或自由编组。自由编组恢复独立单位入场、单机COST上限和每位玩家的单位COST比例设置；其他玩家模式使用常规编组。机库内可切换两种编辑视图，进入房间后服从房间选择。

新存档编组为米迪亚搭载3台扎尼、胖叔叔搭载3台默认机枪套件扎古2F，总COST1100、14容量点。赠送五套：运输机各5台，两类MS各15台；已有存档不补发。收益见[经济规则](economy.md)，库存扣除与单位科技配置不变。

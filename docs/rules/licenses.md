# 部署许可与机体库存

个人进度保留部署许可和机体库存。套件是免费配置，不再作为独立物品购买、生产、奖励、占用或消耗；已有存档中的套件数量在读取时忽略，机体、许可、资金、物资及奖励防重记录保留。

- 购买部署许可仍需科技开发，价格为单台机体生产价格的3倍，首次购买赠送一台机体。
- 已许可且已开发的单位可生产，按单台机体价格每次生产一台，可选择任意合法出厂套件，套件不收费。已许可单位详情中的原许可购买位置显示“生产”。
- 预览及编组可自由切换合法套件；套件的武器性能、战术COST、驾驶员及形态适用性仍按配置校验。
- 未开发、未许可但有机体库存的单位仍可出战并切换套件；生产和补充仍须科技与许可。一键补充遇到无法生产的单位会提示，整笔操作不扣费。
- 常规战、雇佣兵战争和战场扫荡仅在最终结算时统一扣除真实阵亡数量、发放本局奖励，退出或断线不应用暂存记录；快速战可凭部署许可出战，阵亡不扣库存。雇佣兵战争和扫荡的局内可用库存仍减去已损失数量，耗尽后无法再次部署或补员。
- 机库普通变形、爆甲及成对BWS形态切换只转换一台库存，不增加总数，不授予目标许可；EXAM等临时系统不属于机库变形。灵格斯及特装型的BWS/MA形态可在机库和生产列表查看，不独立购买许可或生产。
- 历史战役维持独立阵营资源，不需要个人部署许可；生产只收机体费用，换装免费，不能借换装恢复耐久、EN或重置武器次数，交战与运输等状态限制仍生效。
- 活动可奖励许可或指定数量的机体，机体奖励不自动授予科技或许可；旧活动里的独立套件奖励不再发放。

库存及资源收据同笔持久化，重复快照、重连或重复领取不会重复扣减／发放。从战局存档开启的对局和只读回放仍不结算个人经济。原MOD的装备价格保留为导入来源档案，不参与当前套件收费。

AI单位禁用列表仍由 `shared/ai-unit-bans.json` 维护，不影响玩家使用。

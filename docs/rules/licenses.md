# 部署许可、机体与套件库存

普通菜单、常规战和快速战均固定PMC，不再选择玩家阵营。库存和ACE名册统一共用，ACE保留原始阵营作为来源资料；原阵营编组一次性合入PMC，原档保留备份。战略模式仍使用独立阵营部队、驾驶员和经济。

## 默认许可与新存档

所有阵营 `baseTech` 节点解锁的可部署单位默认拥有部署许可；旧档载入时补齐这些许可，不补发库存或货币。添加单位面板提供“全部 / 有库存 / 已许可”筛选；“已许可”按机体含套件的最低 COST 升序排列，仍可叠加搜索、阵营等筛选。

新存档初始资金为10000、物资为20000。初始编组由 `shared/starter-profile.json` 维护：胖叔叔预搭载扎古ⅡS一台、默认机枪套件扎古ⅡF两台；一架米迪亚预搭载六辆61式战车；另一架米迪亚预搭载飞鳐和剑鱼各三架。库存按完整编组准备五组，机体和实际配置的套件分别计数；旧存档的编组与库存保持原样。

## 解锁与生产

1. 各阵营科技点是永久累计进度。满足节点门槛及前置后可开发，不扣科技点、资金或物资；节点原始货币费用继续供战略模式参考。
2. 科技开放后购买机体的永久部署许可。首次付费购买赠送一台机体和一份默认套件，赠品与许可同一事务保存；重复购买不扣费、不重复赠送，战损不撤销许可。
3. 在机库的“生产车间”页选择出厂套件，每次生产一台机体和一份所选套件，分别收费并显示合计。原MOD的批量生产数量只保留作来源档案。
4. 可以在生产页“仅购买所选套件 ×1”，或单位预览中“购买套件 ×1”单独增加一份兼容套件，不增加机体。

机体库存按单位ID保存；套件库存按“单位ID__套件ID”保存。相同名称的不同机体套件不默认通用。常规战每个编组条目占用一台机体及一份所选套件，载员也独立计数；快速战有部署许可时不要求实物库存；无许可时可凭完整机体和所选套件库存出战，数量按库存校验。不同保存编组可以引用同一库存，只有本次实际出战占用实物。

换装只改变当前编组对套件库存的分配。旧套件继续保留，不退款，不自动出售，不凭空生成新套件。库存不足的条目显示原因，无法实际生成；一键补充会列出缺少的许可、机体、套件数量及总价，确认后原子购买。

## 当前价格

- 部署许可：默认套件整机生产总价的3倍，资金与物资分别乘3；价格不随生产界面当前选择的其他套件变化。首次购买赠送默认配置1台，一键补货会抵扣这台机体及默认套件的缺口，避免重复收费。
- 每台机体生产费：继续使用原单机报价基准，即原工厂按台折算并取整的基础价或原改装限定机型的基础价，应用人工价格差值；许可涨价不改变生产费。
- 每份套件：有正数原生换装费用的资源项沿用该费用并向上取整；原生零费用或缺少来源的资源项按机体生产价的20%取整，资金最低25、物资最低50。原生免费换装不代表生产新装备免费。
- 机体和套件均为独立绝对价格，不按默认套件价差收费，因此默认套件更强也不会产生负价或退款。

以上是测试期初始定价，分别由`shared/economy.js`的`unitOffer`、`kitOffer`和`productionOffer`维护。原始价格、套件COST与人工数值差值不由此改写。

## 出战、战损与结算

- 常规战校验个人机体及套件数量；快速战优先使用部署许可，缺少许可时允许库存出战。AI、房间提供的预设部队及战略模式不消耗个人库存。
- 最终编组确认并实际生成单位后，常规战按生成记录预留库存，私人部署收据使个人库存同步扣减，重复快照、请求和重连不得重复扣减。快速战有许可时不校验数量、无许可时校验对应库存数量，但都不扣减个人实物数量，阵亡、退出或中断不造成库存损失。
- 常规战结束，存活单位返还原出战机体及套件，损毁单位不返还；快速战从出战起就不扣个人实物数量，结算也不会重复增加库存。变形及ACE配属使用原出战机体／套件身份结算，不发放衍生形态库存。
- 房主中途返回房间时，常规战只返还当时仍存活的机体和套件、已经发生的战损保留；快速战解除占用，个人库存数量不变。两者都不发胜负货币或科技奖励。常规战未正常结算且未收到返还收据的出战库存仍被占用。
- 从战局存档开启的对局、只读回放不预留或扣除个人库存，也无个人收益。战略库存沿用独立阵营经济。
- 活动赠送部署许可仍只授予永久资格，不自动赠送实物。

## 旧存档迁移

个人经济数据升级为`schemaVersion: 3`，包含`licenses`、`inventory`及`kits`。已有部署许可、资金、物资及奖励防重记录保留，旧版全部机体与套件库存按0处理；更早的正数库存仅用于恢复对应许可。新格式的实物库存重载、导出及导入后继续保留，不再次清零。

迁移前本地原始经济数据备份到经济存储键的`.before-counted-stock`。默认许可仍包含61式、飞鳐、米迪亚、扎古II F、扎古II S和胖叔叔；新档资金5000、物资10000，实物库存为0。

## 原MOD价格档案

`shared/production-catalog.json`中的`offers`、`nativePricing`保留整批报价、数量、生产耗时、来源动作与装备价差；`nativeEquipmentCosts`保留原生换装费用。生成入口为`tools/import-production.py`、`tools/license-catalog.cjs`及`tools/import-equipment-prices.py`。当前购买接口统一按单台／单份处理，不能将档案中的整批数量再次发放。

## AI对战编组禁用名单

`shared/ai-unit-bans.json`按`regular`（常规战）、`quick`（快速战）维护单位ID列表，当前均禁用`MS_06C`的全部套件。名单同时应用于AI随机编组、编组预览及实际部署，不限制玩家，也不影响战略模式。修改后重新构建客户端、重启服务端。


活动可以独立奖励指定数量的机体和套件。完整库存允许未开发、未许可的单位出战，但不自动授予科技或许可；已有套件可以切换，没有部署许可不能购买新套件。生产机体、购买套件仍须开发并持有许可，购买许可仍须满足开发条件。一键补充遇到未开发或无法补充的单位／套件时明确列出原因并保持整笔操作不扣费。

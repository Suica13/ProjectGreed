# 永久部署许可

- 科技开发后，购买一次对应机体的部署许可；同型号可重复加入不同编组或同一编组，仍受阵营、COST、编组点数及房间限制约束。
- 许可价格为原MOD最便宜工厂方案的整批资金／物资分别除以批次数量，再四舍五入到50；正数最低50。购买行为只授予一次永久许可。
- 武器组自由切换，不再购买、储存或预留套件。默认武器组按原MOD `EquipmentIndex == 0` 识别，与报价最低的套件分开。既有编组保留原先选择的武器组。
- 战斗结束仍记录损毁单位，但不撤销许可。快速战和常规战都不消耗单位；存档对局继续无收益、无损失。
- 付费改装操作已移除。普通改装限定机型直接购买部署许可，沿用原改装费并按50取整，不要求先拥有来源机体。ACE专用形态仍由配属自动转换；单位预览的“特殊变换”仅展示对应ACE及其专用机。
- 活动单位奖励授予对应许可；原先奖励的数量不再叠加，活动货币、立即开发和ACE奖励保持原有用途。活动管理页使用单位许可选择，不填写数量。
- 个人经济档案升级为 `schemaVersion: 2`，保存 `licenses: {单位ID: true}`。旧的正数单位库存（包括早期完整模型ID）转换为许可；旧套件库存不再生效。保留资金、物资与奖励防重记录，迁移前原始内容备份到本地经济键的 `.before-deployment-licenses`。
- 个人存档导出、运行时及联机消息统一保存布尔值 `licenses`，旧库存、套件购买、出售及付费改装接口已移除。`shared/profile-migrations.js` 仅在本地存储／存档导入／旧活动存储读取边界转换历史数据，游戏规则不接收旧数量字段。

## 原MOD价格备份

`shared/production-catalog.json` 中：

- `offers`：原始各装备整批报价、数量、生产耗时、源动作及混编明细，保持未取整数据。
- `licenseOffers`：当前模式使用的单机许可报价，与原始报价独立。
- `nativePricing`：按单位备份0号基础装备报价和每种装备的整批价、精确单价，以及相对0号装备的资金／物资差额；差额保留正负值和小数，未匹配报价明确标记不可用，不虚构价格。

生成入口为 `tools/import-production.py`，其中调用 `tools/license-catalog.cjs`；后续模式可读取原始价格，不受当前许可价格取整影响。
- 无许可单位可以先加入编组，但不能实际出击。批量购买按型号去重，任一缺失许可无法购买或货币不足时整笔取消；已许可但未开发的活动单位不会阻塞购买其他单位。

默认许可包含61式、飞鳐、米迪亚、扎古II F、扎古II S和胖叔叔；新档资金5000、物资10000。

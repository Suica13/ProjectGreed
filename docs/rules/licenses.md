# 部署许可与机体库存

个人进度保留部署许可和机体库存。套件是免费配置，不再作为独立物品购买、生产、奖励、占用或消耗；已有存档中的套件数量在读取时忽略，许可、资金、物资及奖励防重记录保留。旧数量库存已迁移为[基地仓储](storage.md)，旧机体库存清空。

- 部署许可不再购买，由任务、活动或后续条件直接发放；已有许可保留，授予许可本身不赠送机体。直接购买和一键补充均不能花费资源取得许可。
- 已许可的单位可生产，不要求科技开发。每次按单台价格生产一台并使用默认套件；生产界面不显示库存数量和出厂套件选项，仅保留未许可提示。生产仍校验阵营、WIP、资源与仓储空位。
- 预览及编组可自由切换合法套件；套件的武器性能、战术COST、驾驶员及形态适用性仍按配置校验。
- 未许可但有机体库存的单位仍可出战并切换套件；生产和补充仍须许可。一键补充遇到无法生产的单位会提示，整笔操作不扣费。
- 常规战、雇佣兵战争和战场扫荡仅在最终结算时统一扣除真实阵亡数量、发放本局奖励，退出或断线不应用暂存记录；快速战可凭部署许可出战，阵亡不扣库存。雇佣兵战争和扫荡的局内可用库存仍减去已损失数量，耗尽后无法再次部署或补员。
- 机库普通变形、爆甲及成对BWS形态切换只转换一台库存，不增加总数，不授予目标许可；EXAM等临时系统不属于机库变形。灵格斯及特装型的BWS/MA形态可在机库和生产列表查看，不独立购买许可或生产。
- 活动可奖励许可或指定数量的机体，机体奖励不自动授予科技或许可；旧活动里的独立套件奖励不再发放。

库存及资源收据同笔持久化，重复快照、重连或重复领取不会重复扣减／发放。从战局存档开启的对局和只读回放仍不结算个人经济。原MOD的装备价格保留为导入来源档案，不参与当前套件收费。

AI单位禁用列表仍由 `shared/ai-unit-bans.json` 维护，不影响玩家使用。


## 形态、套件与特殊载具

灵格斯以BWS形态展示和生产；灵格斯特装型以人形展示，MA形态仅通过变形使用。普通变形与爆甲可在机库中装回；按同一条普通形态转换链检查真实库存，转换只移动一台机体，既不新增库存也不另购形态许可。EXAM、HADES等战斗系统不包含在机库形态转换中。

吉莱、强袭高达的衍生型号作为本体套件，分别保留各型号原先COST最高的一套武装；各套件沿用该型号的骨架、外观、武器、技能和性能。原型号不再作为独立生产条目，旧编组映射至本体对应套件，原型号库存累计至本体，部署许可也随之归并；重复读取不会重复迁移。

SFS可作为常规编组的独立舰船槽位出击，也可照常被运输单位搭载，仍计入舰船数量和编组总COST。原MOD单次生产一台的非战舰单位，基础COST采用既有UnitLevel换算后乘1.10并按25取整，套件差价和人工差值随后应用。手工指定价格维持既有数值。MA耐久仍为原始值的75%，本轮不重复削减。

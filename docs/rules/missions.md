# 合约模式：任务模式

任务是固定脚本的多人合作战斗。所有玩家加入队伍1，队伍2为关卡控制的敌军。当前合作地图支持1至5名玩家。关卡地图提供年代上限、科技点上限、编组COST和容量点；玩家可使用所选年代及更早且符合科技门槛的库存单位。剧情部队不消耗玩家编组预算与库存，默认交由参战房主控制；房主转移时移交现存剧情部队。若房主是观战者或离线，则由在线参战玩家代管剧情与部队，不等待观战者。玩家自带部队沿用最终结算处理损失与奖励的机制。

## 三分钟十二台大魔

- 年代0079T2，科技点上限10000，玩家各1200 COST／12容量点。白色基地位于地图稍靠左、朝右；PMC共享部署区分布在其上、下两侧。敌方舰队靠右、朝左。
- 开场敌军：十二台力克大魔，默认三机一队，共四队；另有三艘契贝级。我方剧情单位WhiteBase由房主控制。
- 敌军耐久和EN上限倍率为`1 + 0.25 × (参战玩家数 - 1)`：1至5人分别为100%、125%、150%、175%、200%。开战时固定人数，观战者不计入，后续增援沿用该倍率，不提高敌方伤害等其他属性。
- 胜利：消灭所有已登场敌军。失败：全部玩家PMC单位被击坠，或WhiteBase被击坠。
- 在第10回合及之前击破至少六台任务力克大魔，触发一次额外事件：右侧出现夏亚专用勇士（ACE夏亚Lv3），左侧出现高达（ACE阿姆罗Lv3）。追加阿姆罗高达被击坠即失败，敌军歼灭目标也包括夏亚。
- 开场与增援事件的台词、头像、镜头目标均来自地图脚本。对话期间禁止战术动作与AI推进，房主逐句继续；观战者不参与推进屏障。相同请求ID不会重复推进，过期对话位置会被拒绝。
- 每名参战玩家通关获得2台钢加农库存、2000资金、3000物资；触发增援事件后通关额外获得1台高达、2000资金、3000物资，合计4000资金、6000物资。失败不发放通关奖励。不再叠加普通遭遇战基础奖励与科技点，活动资金/物资倍率仍按现有结算机制生效。单位奖励只增加库存，不授予部署许可。

事件在部署完成及战斗批次演出完成后的安全状态检查，不在渲染帧中轮询。先处理条件事件和增援，再检查歼灭胜利；失败条件优先。常规战、历史战役、战争和扫荡仍使用各自原有胜败裁定。

制作说明见[地图编辑器](../tools/map-editor.md)。

事件运行时支持多条件的全部/任一组合、指定单位或分组全灭、前置事件完成，以及增援、保护目标增减、恢复状态、任务提示和对话等顺序动作。所有触发、恢复与胜败仍由共用服务端规则裁定，编辑器预览不执行游戏逻辑。

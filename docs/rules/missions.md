# 合作模式：任务模式

任务是固定脚本的多人合作战斗，强制使用完全战争迷雾并允许驾驶员，房间内不可关闭；服务器在创建、修改设置、开战和读取旧战局存档时统一执行。所有玩家加入队伍1，队伍2为关卡控制的敌军。当前合作地图支持1至5名玩家。关卡地图提供年代上限、科技点上限、编组COST和舰船数量上限；玩家可使用所选年代及更早且符合科技门槛的库存单位。剧情部队不消耗玩家编组预算与库存，默认交由参战房主控制；房主转移时移交现存可控剧情部队；标记为独立AI的友军不转交给玩家。若房主是观战者或离线，则由在线参战玩家代管剧情与部队，不等待观战者。玩家自带部队沿用最终结算处理损失与奖励的机制。

## [0079][剧情]相逢在宇宙-EFSF

- 年代0079T2，不限制科技点，玩家各3000 COST，沿用常规编组舰船限制；任务模式隐藏并忽略禁用标签设置。白色基地位于地图稍靠左、朝右；PMC共享部署区分布在其上、下两侧。敌方舰队靠右、朝左。
- 开场敌军：十二台力克大魔，默认三机一队，共四队；另有两艘姆塞后期型和一艘契贝级（中间）。我方剧情部队为白色基地、凯·西汀和小林隼人各驾驶一台钢加农、雪拉驾驶核心推进器，后三名驾驶员均为Lv3，默认由房主控制。
- 敌军耐久和EN上限倍率为`1 + 0.25 × (参战玩家数 - 1)`：1至5人分别为100%、125%、150%、175%、200%。开战时固定人数，观战者不计入，后续增援沿用该倍率，不提高敌方伤害等其他属性。
- 胜利：消灭所有已登场敌军。失败：全部玩家PMC单位被击坠，或WhiteBase被击坠。
- 在第10回合及之前击破至少六台任务力克大魔，触发一次额外事件：右侧出现高达（阿姆罗），登场时以剧情攻击击破剩余敌方舰船；左侧出现夏亚专用勇士及艾尔美斯（拉拉·辛Lv5）。追加阿姆罗高达被击坠即失败，敌军歼灭目标也包括夏亚和拉拉。
- 开场与增援事件的台词、头像、镜头目标均来自地图脚本。对话期间禁止战术动作与AI推进，房主逐句继续；观战者不参与推进屏障。相同请求ID不会重复推进，过期对话位置会被拒绝。
- 每名参战玩家通关获得4000资金、6000物资、3台吉姆和1台钢加农库存；触发增援事件后通关额外获得1500资金、2250物资、1台G-3高达和2台吉姆加农，合计5500资金、8250物资。失败不发放通关奖励。不再叠加普通遭遇战基础奖励；科技点按下文任务固定奖励发放，活动资金/物资倍率仍按现有结算机制生效。单位奖励只增加库存，不授予部署许可。

事件在部署完成及战斗批次演出完成后的安全状态检查，不在渲染帧中轮询。先处理条件事件和增援，再检查歼灭胜利；失败条件优先。常规战、历史战役、战争和扫荡仍使用各自原有胜败裁定。

制作说明见[地图编辑器](../tools/map-editor.md)。

事件运行时支持多条件的全部/任一组合、指定单位或分组全灭、前置事件完成，以及增援、保护目标增减、恢复状态、任务提示和对话等顺序动作。所有触发、恢复与胜败仍由共用服务端规则裁定，编辑器预览不执行游戏逻辑。

剧情攻击：编辑器可指定攻击单位与敌方脚本单位列表；服务端按剧情直接击破目标，客户端播放攻击姿势、弹丸及击破表现。适合增援登场等预设演出，不重复计算普通武器伤害。

原先新增的十一关已移除；目前提供“相逢在宇宙”、原创护送任务“绝不上当”、原创海岸要塞任务“人口过剩”、原创夜袭任务“彻夜难眠”，以及0087合作任务“燃烧的新都市”和“危机的时间限制”。


## [0079][原创]绝不上当-EFSF

- 地面护送任务，年代上限 UC_0079_T1，不额外限制科技点；每名玩家2000编组COST、最多3艘舰船，支持1至5人合作。地图中间为直线公路，两侧为树林和草地，共享部署区位于西侧。
- 大托盘自动沿15个路径点前往东侧绿色框目标区，每个游戏显示回合推进一次。道路畅通时第15回合抵达，第17回合完成驻留胜利。道路被其他单位阻挡时暂停并记录提示，不穿过单位；清理道路后下一回合继续。大托盘不接受手动控制；任务面板显示推进与坚守进度。
- 第2回合增援两队剑鱼，每队3台，由参战房主控制。
- 第3回合：公路两侧各1台老虎飞行实验型；正面6台扎古II F2后期型，分装在两架胖叔叔中，每架3台。
- 第6回合：正面3台伊芙利特，分别搭乘3架德戴II；另有一架胖叔叔搭载3台扎古II F2后期型。
- 第10回合：目标区两侧出现6台大魔，三机一队，共两队。
- 隐藏胜利：全部三波敌军（包括运输机与SFS）均已登场并被消灭时提前胜利；消灭当前一波不会跳过后续增援。失败条件为大托盘被击毁或玩家PMC部队全灭，优先于所有胜利条件。每名参战玩家通关获得4000资金、6000物资、3台陆战型吉姆；触发三波全歼事件后通关，额外获得1500资金、2250物资、1台陆战型高达及2台老虎飞行实验型，合计5500资金、8250物资。失败不发放通关奖励。
- 通用脚本新增护送胜利条件 `escort`（目标单位、矩形目标区、驻留回合、每回合路径点、可选全歼胜利）及单位 `carrier` 预先搭载引用。增援先创建所有单位，再按真实格纳库容量及兼容标签挂载乘客；SFS乘客沿用外露搭载规则。地图编辑器可编辑路径与目标区，单位重命名同步更新搭载引用。


点击战斗界面上方“任务目标”按钮，在屏幕中央打开目标面板，分区查看胜利条件、失败条件及实时计数。护送任务分别展示路径推进和抵达后的存活回合；失败条件分别统计PMC单位损失及每个保护目标被击毁的情况。所有计数来自服务端完整战局，不受当前客户端战争迷雾隐藏单位的影响；剧情增援追加保护目标时会同步更新。可用关闭按钮、ESC或点击面板外关闭。


## [0079][原创]人口过剩-EFSF

- 0079T2年代上限，不额外限制科技点；每名PMC玩家4500编组COST、最多2艘舰船，支持1至5人。共享部署区在西侧，直线战线向东推进，最右端为沙滩、海洋及装饰性质量投射器。
- 初始敌军：3艘达布德级，27台MS（三机一队，扎古II F型、J型及大魔各9台），12座二级机枪／光束／导弹／加农炮塔（每种3座）。敌军不额外按玩家人数提高耐久。
- 第2回合我方3队吉姆（每队3台）；第4回合2队量产型钢坦克（每队3台），均由当前参战指挥玩家控制，不消耗PMC库存。
- 第3回合，6台扎古II F型、6台J型，分装4架胖叔叔（每架3台）；第6回合，6台大魔徒步出击、6台扎古II F2后期型搭载2架胖叔叔；第10回合，目标区域出现6台勇士陆战型。
- 所有三波主力都登场，且3艘达布德级及所有主力MS被击破后，吉翁军指挥官请求停火。未登场的波次会阻止提前触发；存活炮塔及运输机不阻止停火请求。先播放9句全频段呼叫、停火请求及上报对话，再显示A/B选择。对话及选择期间暂停战术操作、AI和自动结束回合；所有玩家同步查看，仅当前参战指挥玩家可决定。
- A：接受停火，播放8句总指挥部批准与停火对话，结束后胜利。每名参战PMC获得5000资金、7500物资、6台吉姆狙击特装型（RGM-79SC）及6台吉姆防御特装型（RGM-79HC）。
- B：拒绝停火，播放9句总指挥部拒绝与吉翁最后抵抗对话，结束后增援9台旧扎古、6台扎古II J型、3台大魔、1台大魔热带式样（MS-09D）、1台伊芙利特、2台老虎飞行型（MS-07H8），均徒步出击。此时须消灭所有剩余敌军，包括炮塔和运输机，方可胜利；每名参战PMC获得7500资金、10000物资、3台吉莱（RX-81）及9台吉姆改。此奖励替换A结局奖励，两份库存不叠加；按本关指定物资数值发放，不套用1:1.5重新换算。
- PMC部队全灭则失败，通关奖励为零。重复选择请求不重复增援或发奖；非指挥玩家、无效选项和过期版本请求被服务端拒绝。
- 通用脚本支持 `choice` 动作、`choice_selected` 和 `all_enemies_destroyed` 条件、`scripted` 胜利类型及 `rewards.outcomes` 替换结局奖励。`fleetLimit` 可为关卡独立设定舰船上限，其他现有任务默认仍为3艘。地图编辑器可直接维护这些配置。

- 45×45九龙黄昏街区，0087T1年代上限，无额外科技点门槛；每名PMC玩家6000编组COST、2艘舰船，支持1至5人合作。固定黄昏、晴天，不参与昼夜循环。玩家从西侧共享部署区出击。横向道路为3格宽，楼宇及其窗户、火点按单位占格统一缩小绘制。
- 开场9台尼莫（三机一队，共3队），对阵18台高扎古（6队）和3台玛拉塞（1队）。全部奥古剧情友军由独立AI控制，使用黄色脚下标记；即使开启友军共享，玩家也不能接管，不占用5个玩家席位，不计入PMC库存损失。

- 第16回合从北侧和南侧各增援3台德戴改，每台实际预先搭载2台尼莫，均为不可控AI友军。第21回合播放撤退警告，存活精神感应高达优先向地图右侧移动；到达边缘的当回合仍可受攻击，下一显示回合才离场。重复同步不会缩短这一窗口。
- 没有目标逃脱且三台均被击毁时，左侧增援8台德戴改、16台尼莫，摄像机聚焦援军，播放确认击毁台词，结束后胜利。第21回合后成功击毁所有尚未逃脱目标也沿用此结局。每名参战PMC获得12000资金、18000物资、百式1台、尼莫6台、奥古式样吉姆II 6台。

## 任务调整与夜袭撤离任务

- 相逢在宇宙：每名玩家3000编组COST；夏亚增援额外携带两队扎古II后期型和一队力克大魔，各三台。
- 人口过剩：地图57×31，移除废墟；初始MS27台、炮塔12座，原有三波增援与B分支保持不变。

### [0079][原创]彻夜难眠-ZEON

0079T1、5000编组COST、两艘舰船、最多五人合作。方形基地五个候选停机位随机选择三个，目标米迪亚不会移动。必须在第30回合结束前摧毁三架目标，并将全部存活友军撤离到西南撤离区；搭载乘客随运输单位一起计算。击毁三架目标后出现友军胖叔叔并开放撤离区。第10回合基地外围出现两队剑鱼及两架核心推进器。击毁吉姆指挥官延长时限20回合并触发追加增援；第30回合仍会天亮。击毁全部初始守军、目标及两批增援后获得额外奖励，依然必须撤离。

每名玩家基础通关奖励6000资金、8000物资、伊芙利特3台、大魔6台；完成全歼额外获得3000资金、4500物资、勇士陆战型3台、扎古II F2后期型6台。失败不发通关奖励。

### 科技点与击杀奖励

上述五个任务通关科技点1000，完成额外条件通关为1500；人口过剩A结局1000、B结局1500，新都市全歼三架目标1500、目标撤离分支1000。按携带单位阵营比例分配，排除科技已满阵营，保留活动科技倍率，不额外应用胜负倍率。

击杀奖励另行累计：以目标单机生产资金价格为基准，击杀获得10%资金及对应1.5倍物资；其他玩家累计造成至少目标最大耐久25%的伤害，获得5%资金及对应1.5倍物资助攻奖励。保留强度与活动倍率，每项按25取整；同一目标不重复奖励。击杀不额外产生科技点。奖励与玩家库存损耗统一在最终结算应用。

## 作战简报

进入部署时自动打开与合约模式共用的作战简报，展示实际战场地图、胜利／失败条件，并依次高亮目标位置与介绍。地图带自上而下雷达扫描，手动点选可定位目标，右下角关闭后继续部署。可在战斗上方“任务目标”面板内点击“作战简报”重看；不要求其他玩家确认，不阻塞联机推进。剧情对话或剧情选项出现时自动收起简报。

每次剧本事件触发或胜利／失败条件的结构、目标数量发生变化，会在本轮全部对话、选项、后续动作和战斗演出结束后重新打开简报。连续演出期间的更新合并展示最新目标；击坠计数或生存回合数单纯增加不会反复弹出。每次打开播放声纳提示音，服从音效音量与静音设置；每4.5秒介绍下一项目标。地图标记用进攻箭头、防守盾牌、移动箭头、撤退箭头区分目标。

部署按钮区提供“左转90°／右转90°”。选中待放置或已部署的舰船均可操作，朝向即时生效；已放置舰船仍需满足最终占地、部署范围和碰撞限制，不占用首回合行动。

# 驾驶员与指挥

以shared/pilots.js、shared/pilots.json及共享战斗规则为准；单位和驾驶员的反应影响回避，机动只影响移动，不产生AP加成。

自定义驾驶员初始0级、最高10级，六项基础属性100、指挥80、觉醒60；初始80强化点，每升一级40点。属性上限从125按每级+10提高，最高200。经验为累计需求1000×目标等级²，10级100000；经验足够后手动升职并支付资金，不自动升级。降职和升职不清空累计经验；重置属性同时重置自选技能。

6级可选一个技能，具体候选由pilots.json维护。技能属性增益1.35倍、持续1个己方回合、结束后冷却5个己方回合。成长和强化后的八项属性最终四舍五入为整数，不重复对基础值累计倍率。

射击、格斗、命中、反应倍率为max(0.5,1+(属性−100)×0.0025)。防御最终承伤倍率为max(0.05,1−(防御−100)×0.0025)。机动移动倍率为max(0.5,1+(机动−100)×0.005)，最终移动格数取整数。觉醒达到100时另有1.075倍伤害；浮游武器另有觉醒门槛及伤害规则。

ACE固定名称及头像、不能手动加点或重置，0至5级按原MOD满级上限的几何曲线成长；初始250 COST、每级+25。升职资金等于招募价，降职亦同；具体累计经验阈值见pilots.js。待回归重新招募按半价，保留等级与战绩并清空经验。PMC可配属任何ACE，其余身份需匹配主/副阵营。旧小数成长值仅接受原精确曲线结果，导入后统一为整数。

指挥光环在100领导力时范围3格、效果10%。steps=trunc((领导力−100)/25)，范围=max(1,3+steps)，效果=max(0,0.10+0.01×steps)。攻击加最终射击/格斗伤害，防御减最终伤害，通信影响命中/回避；同类取最高，不叠加。范围不因本次AP清理改变。

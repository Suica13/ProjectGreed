# 驾驶员与指挥

以shared/pilots.js、shared/pilots.json及共享战斗规则为准；单位和驾驶员的反应影响回避，机动影响移动及攻击轮数，不产生AP加成。

PMC驾驶员初始0级、最高8级，六项基础属性100、指挥80、觉醒60；初始80强化点，每升一级40点。属性上限从125按每级+10提高，最高200。累计经验需求依次为500、1500、3000、5000、10000、15000、20000、30000；经验足够后手动升职并支付资金，不自动升级。降职和升职不清空累计经验；重置属性同时重置自选技能。

6级可选一个技能，具体候选由pilots.json维护。技能属性增益1.35倍、持续1个己方回合、结束后冷却5个己方回合。成长和强化后的八项属性最终四舍五入为整数，不重复对基础值累计倍率。

射击、格斗、命中、反应倍率为max(0.5,1+(属性−100)×0.0025)，每点增加0.25个百分点，100点为100%、200点为125%。防御最终承伤倍率为max(0.05,1−(防御−100)×0.0025)，200点时承伤75%。机动移动倍率为max(0.5,1+(机动−100)×0.005)，最终移动格数取整数。觉醒达到100后命中、回避各增加10个百分点，不再额外提高普通伤害；浮游武器另有觉醒门槛及伤害规则。

ACE固定名称及头像、不能手动加点或重置，0至5级按原MOD满级上限的几何曲线成长；基础COST按满级八项属性总和在所有ACE之间线性映射到200～300并按最近的25取整、每级+25。升职资金等于招募价，降职亦同；累计经验需求依次为1500、3000、5000、10000、20000。待回归重新招募按半价，保留等级、累计经验与战绩。普通菜单、常规战与快速战统一PMC名册，可配属任何ACE；战略模式保留阵营差异，需要匹配主/副阵营。旧小数成长值仅接受原精确曲线结果，导入后统一为整数。

指挥光环在100领导力时范围3格、效果10%。steps=trunc((领导力−100)/25)，范围=max(1,3+steps)，效果=max(0,0.10+0.025×steps)。攻击加最终射击/格斗伤害，防御减最终伤害，通信影响命中/回避；同类取最高，不叠加。范围不因本次AP清理改变。

普通射击轮数倍率为（机体机动÷100）×max(0.5,1+(驾驶员机动−100)×0.005)，乘基础轮数后四舍五入、至少1轮。格斗、技能、腕部、头部火神炮及驾驶员门槛武器仍限1轮，其他每回合次数上限照常生效；舰毁强制脱出随后向下折半，最小0轮。驾驶员100机动时轮数系数100%，200时150%。

普通驾驶员名册提供全部、PMC驾驶员与各ACE主／副阵营筛选。常规战、快速战可设置允许、禁止PMC驾驶员、禁止ACE或全部禁止配属驾驶员；保留单位默认驾驶员。阵营禁用标签中的`pilot:custom`及`pilot:<阵营>`独立约束驾驶员，不禁用同阵营机体。

驾驶员击毁基础经验为`100 × 敌方机体COST / 自身机体COST`，两侧均包含当前套件、不包含驾驶员附加COST；助攻取25%，再应用对手／强度系数、经验活动及技能／机体经验倍率并向下取整。快速战再乘10%；满级不给战斗经验。战略模式沿用比例基础与机体／技能经验倍率，不读取个人活动收益。

旧版6驾驶员迁移到新版7：9／10级PMC驾驶员降到8级，累计经验与战绩保留；已用强化点超过新预算时退还全部加点。

驾驶员卡片在头像下统一显示“已招募”或“待回归”，PMC驾驶员也显示已招募；标题按名字、等级、阵营／年代排列。存档的`custom`字段、ID和房间策略`no_custom`保留兼容，只调整显示名称。

驾驶员战绩仅记录击坠单位数、击坠战舰数、参战次数与被击坠数；不再记录累计击坠COST和被击坠COST，旧存档导入时忽略这两项。

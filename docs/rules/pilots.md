# 驾驶员与指挥

基地宿舍分为PMC驾驶员和ACE驾驶员两个页面，电脑版每页两排十张卡片，手机版每页两列四张卡片，底部翻页。PMC页面管理自定义驾驶员，ACE页面管理已招募ACE。士兵招募入口和老兵、精英、强化人配属选项已移除，既有库存数据保留。

宿舍列表按可用空间完整显示本页卡片，不使用列表滚动条；翻页栏固定在底部中央。搜索和筛选只改变显示。点击排序按钮可选择名称升序、等级降序或COST升序，保存当前PMC或ACE分类的完整顺序，另一分类不变。

宿舍卡片顶部显示姓名和COST；中间显示头像，左上角为年代／阵营标签，右下角为“待机中”或“待回归”。下方40像素固定区域显示等级、经验、强化点及可升级等状态，最底部固定显示最多两个技能，额外技能以省略号提示。各区域高度固定，不随技能数量变化；点击卡片或按Enter／空格打开驾驶员详情，不再显示详情和删除按钮。

驾驶员详情中，PMC与ACE共用等宽的头像／属性左列和状态／技能机制右列；等级栏显示当前等级／等级上限（例如Lv0/8），COST仅在标题处显示。两类驾驶员共用属性强化、技能说明、成长机制及复归费用卡片。ACE仍按悟性自动成长，强化、重置及技能选择控件保留相同位置但禁用；PMC保留已有手动强化与技能选择规则。

机库及编组默认使用免费的一般PMC驾驶员，仍可配属自定义PMC或ACE。一般PMC的属性范围与阵营一般驾驶员一致，指挥单位沿用一般指挥官范围；战斗属性由服务端按私有种子生成，不接受客户端传入的随机结果。头像按库存单位或已选驾驶员标识稳定随机，重新打开和读档不会变化。一般PMC不占士官学院自定义驾驶员名额，不参与升职、转生和个人技能成长。

以shared/pilots.js、shared/pilots.json及共享战斗规则为准；单位和驾驶员的反应影响回避，机动影响移动及攻击轮数，不产生AP加成。

PMC驾驶员初始0级、初始等级上限8，六项基础属性100、指挥80、觉醒60；初始80强化点，每升一级40点。属性上限从125按每级+10提高，最高200。0至8级累计经验需求依次为500、1500、3000、5000、10000、15000、20000、30000；8至12级依次需要200000、3000000、4000000、5000000累计经验。经验足够后手动升职并支付资金，不自动升级。降职和升职不清空累计经验；重置属性同时重置全部自选技能。

达到当前等级上限时可转生，最多4次；每次上限提高1级，最终12级。转生费用是当前等级对应升职价格的两倍：80000、100000、120000、140000资金。转生后等级0、经验0、恢复基础属性及初始80强化点、清除已选技能，保留名字、头像、性格、互动文本与战绩。9至12级升职价格依次为40000、50000、60000、70000资金。6级可选第一技能，12级可选不同的第二技能，二者共用正常战斗技能机制。ACE保持原成长规则，不可转生。

名册经验行依次显示转生次数（一转至四转）、可升职、强化点+，只显示当前适用的标签。驾驶员COST标签不带加号。PMC详情隐藏出身阵营选择，将互动文本按钮放在原位置；始终可编辑，保存台词时切换到自定义性格。每事件默认一个独立台词输入框，通过加号增加，最多10条；旧存档中的12条池保留前10条。JSON导入仍严格校验内容，空事件沿用默认台词。

6级可选一个技能，具体候选由pilots.json维护。技能属性增益1.35倍、持续1个己方回合、结束后冷却5个己方回合。成长和强化后的八项属性最终四舍五入为整数，不重复对基础值累计倍率。

射击、格斗、命中、反应倍率为max(0.5,1+(属性−100)×0.0025)，每点增加0.25个百分点，100点为100%、200点为125%。防御最终承伤倍率为max(0.05,1−(防御−100)×0.0025)，200点时承伤75%。机动移动倍率为max(0.5,1+(机动−100)×0.005)，最终移动格数取整数。觉醒达到100后命中、回避各增加10个百分点，不再额外提高普通伤害；浮游武器另有觉醒门槛及伤害规则。

ACE固定名称及头像、不能手动加点或重置，0至5级按原MOD满级上限的几何曲线成长；基础COST按满级八项属性总和在所有ACE之间线性映射到150～250并按最近的25取整、每级+25。升职资金等于招募价，降职亦同；累计经验需求依次为1500、3000、5000、10000、20000。PMC与ACE阵亡后均进入待回归，正式结算保存；PMC复归费用为每级500物资，ACE为每级1000物资，均不消耗资金。复归保留等级、累计经验、属性、技能与战绩。宿舍左下角一键复归先选择本页或全部，随后确认总费用；详情面板也可单名复归。士官学院每级分别提供10名PMC与10名ACE容量，旧名册超额不删除，但不得继续招募超限类别。普通菜单与快速战统一PMC名册，可配属任何ACE；旧小数成长值仅接受原精确曲线结果，导入后统一为整数。

指挥严格高于100时激活光环。非舰船基础范围2格，舰船4格；支援／一般默认通信指挥，泛用默认防御指挥，突击默认攻击指挥。机体原有指挥技能替换默认类型，额外增加2格范围；零件和天赋范围另加。效果为10%+floor((指挥−100)/25)×2.5%。攻击提高最终伤害，防御降低最终伤害，通信提高命中与回避；同类取最高，不叠加。

自定义PMC招募时没有天赋，首次达到4级获得第一个随机天赋，第一次转生获得第二个，第二次转生获得第三个，后续转生不再增加。最多三个且不重复。已有驾驶员保留已获得天赋，并按等级和转生次数补齐；转生和降职保留天赋与已解锁次数，不因读档重抽。详见[驾驶员天赋](../design/pilot-talents.md)。

普通射击轮数倍率为（机体机动÷100）×max(0.5,1+(驾驶员机动−100)×0.005)，乘基础轮数后四舍五入、至少1轮。格斗、技能、腕部、头部火神炮及驾驶员门槛武器仍限1轮，其他每回合次数上限照常生效；舰毁强制脱出随后向下折半，最小0轮。驾驶员100机动时轮数系数100%，200时150%。

普通驾驶员名册提供全部、PMC驾驶员与各ACE主／副阵营筛选。常规战、快速战可设置允许、禁止PMC驾驶员、禁止ACE或全部禁止配属驾驶员；保留单位默认驾驶员。阵营禁用标签中的`pilot:custom`及`pilot:<阵营>`独立约束驾驶员，不禁用同阵营机体。

驾驶员击毁基础经验为`100 × 敌方机体COST / 自身机体COST`，两侧均包含当前套件、不包含驾驶员附加COST；助攻取25%，再应用对手／强度系数、经验活动及技能／机体经验倍率并向下取整。快速战再乘10%；满级不给战斗经验。战略模式沿用比例基础与机体／技能经验倍率，不读取个人活动收益。

旧版6驾驶员迁移到新版7：9／10级PMC驾驶员降到8级，累计经验与战绩保留；已用强化点超过新预算时退还全部加点。

驾驶员卡片在头像下统一显示“已招募”或“待回归”，PMC驾驶员也显示已招募；标题按名字、等级、阵营／年代排列。存档的`custom`字段、ID和房间策略`no_custom`保留兼容，只调整显示名称。

驾驶员战绩仅记录击坠单位数、击坠战舰数、参战次数与被击坠数；不再记录累计击坠COST和被击坠COST，旧存档导入时忽略这两项。


## 通用驾驶员库存

未配属时使用单位所属阵营的一般驾驶员或一般指挥官。老兵的非觉醒属性为一般版本的120%，COST+50，招募250资金；精英为140%，COST+150，招募750资金；强化人仅有驾驶员，非觉醒属性150%、觉醒75至110，COST+250，招募1250资金。三档库存跨阵营、跨驾驶员／指挥官角色共用，配属不立即消费，击坠损失在对局结算时按服务端记录扣除一次。无效配属或库存不足自动改回一般驾驶员。通用ACE属性160%，仅提供脚本接口，不向玩家开放选择。具名ACE和PMC驾驶员沿用各自成长规则。

在驾驶员名册顶部或机体的驾驶员配属列表中招募；配属列表按机体所属阵营显示名称与指挥官角色。普通驾驶员库存保存在经济存档的crewStock中，旧存档默认三个库存均为0。

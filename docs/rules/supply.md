# 补给扭蛋机

联络终端的补给分页提供三个独立奖池，各消耗自己的补给代币，每次1枚。十连独立抽取，无额外保底；所有永久机和租赁机送至保管库。保管库达到200台时禁止抽取。代币可以通过活动赠送，存档不会自动发放测试代币。

阿纳海姆「购买」页也出售代币：0079年代每枚10000资金，天人、雷霆宙域各每枚30000资金。分别交付独立委托「现货凭证」「匿名账户」「封箱条款」后开放对应商品；三项均为0079T1地面、N5以上武装介入，不依赖原有任务线或彼此的完成情况。购买每次一枚，存入道具库存，扣费与发放共用保存事务。详细目标见[阿纳海姆联络人](../design/anaheim-contact.md)。

雷霆宙域S品：全装甲高达TB、精神力扎古TB永久机。A品：吉姆TB、扎古II TB永久机合计7.5%，S品5次租赁机合计7.5%。B品：A品5次租赁机合计15%，S品3次租赁机合计15%。各类内部机体等概率；武装切换及脱甲形态不单独入池。

天人S品：能天使、力天使、主天使、德天使永久机，各1.25%。A品：上述机体5次租赁机，合计15%。B品：上述机体3次租赁机，合计30%。主天使MA为变形形态，不单独入池。所有奖池的新租赁奖励按旧20次→5次、10次→3次、5次→1次调整，已持有机体次数保持不变。

全部奖池的C品沿用相同内部权重：物资25、资金25、本池代币×1为4、0079年代稀有度1/2/3零件为16/8/4。两个新池按C品50%缩放，因此对应单抽总概率为15.243902%、15.243902%、2.439024%、9.756098%、4.878049%、2.439024%。全部奖池物资和资金均为1000–3000整数。

运行数据：[奖池配置](../../shared/supply-pools.json)。游戏内“商品一览”显示各奖项的单抽概率、机体与租赁次数。

所有扭蛋机卡片使用相同固定尺寸。双机在两侧背靠背朝外；四机以相同高度的2×2画面向四角朝外。右侧注目封面沿用相同朝向；只有左侧卡片列表可滚动，主分页不增加滚动条。

保管库新增单位上限200台；抽取前须有足够空位容纳本次最多可获得的单位数量。活动和任务奖励超出容量时不入账、不消耗领取凭证，可领取现有单位腾出位置后重试。旧存档已存在的超限单位保留。

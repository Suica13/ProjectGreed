# 合约模式：战场扫荡（V113）

创建房间时选择“合约模式 → 战场扫荡”，房间展示固定任务封面，不提供手动选图入口。房主可选择地面或宇宙环境；每次战斗按己方作战人数（含友方AI，不含观战者）从同环境、可容纳人数的最小席位规格遭遇战地图中随机抽选，有其他候选时避免连续重复。房间最多提供五个PMC席位。队伍1为PMC协作方，队伍2在房间和确认编组界面隐藏；每个己方作战席位对应一个独立编组的敌军AI。房主选择敌军阵营、年代和常规编组限制。所有客户端同步查看同一任务路线，由房主选择已连线的下一节点并确认，一起进入战斗或事件。

## 路线与敌军

任务地图嵌入战斗场景的地图区域，复用顶栏与下方聊天、频道、LOG及信息栏展开／收起控件。电脑左侧显示剩余部队，手机将部队列表收纳为折叠面板；事件与补员也在同一区域显示。任务地图期间暂停底层战场渲染，进入节点战斗后恢复。

路线每层有两到三个节点，无终点；节点通常只有一条出口，部分具有两条，所有节点均有来路，不再全连线。前方节点按需生成，已远离的路线自动回收。节点包括普通战斗、精英战、休息区和随机事件，当前不含商店。每第五层中间为休息区、存在的两侧节点为精英战，其余层随机生成。

敌军来自所选阵营和年代，并遵守地图环境、禁用标签与AI禁用名单。第一节点深度为0，每经过一个节点（包括事件、休息）增长系数为 `1.05^深度`。每个敌军AI的编组总COST上限为房间编组上限的50%乘增长系数；单机COST上限分别为房间单机上限的75%（普通）和125%（精英）乘增长系数，向下取整。编组上限遵守引擎99999上限。为使无限推进始终存在符合奖励质量的现有机体，实际单机上限限制在本年代奖励池最低COST/1.25向上取整至最高COST的2倍之间，最高不超过99999。

## 战利品与结算

每位玩家的普通胜利基础奖励降为375资金、750物资、75科技点，乘以 `max(0.25, min(个人入场COST, 房间编组上限) / 2000) × 1.05^深度`，分别向下取整。精英战资源为两倍。每次普通胜利奖励1台随机单位库存，精英胜利奖励3台，允许抽到重复单位和舰船。奖励池使用所选年代的默认套件实际COST，范围为该节点实际敌军单机COST上限的50%～125%，排除设施、WIP、隐藏形态和驾驶员专属机。科技按携带机体阵营比例分配，排除已满科技阵营。事件资源同样使用降低25%后的基准和逐节点增长系数。

所有奖励先留在本局，不进入个人钱包或机库，暂存栏显示倍率前数值。完成节点并返回任务地图后，房主可用右上角“撤离战场”使全队一起结算。最终应用现有全局1.25及活动倍率。全体人类玩家部队全灭时强制结算，资金、物资、科技点减半，已获得机体库存完整保留。每人使用独立、可去重的结算收据；库存奖励不授予部署许可。

机体真实阵亡立即扣除个人库存，与常规战、雇佣兵战争统一；不会等到撤离重复扣减。断线本身不判定所有机体阵亡。战斗之间保存耐久、EN、盾、部位、弹药与永久使用次数，回合指令及临时系统不会跨战斗延续。每位玩家的存活编队中若仍有补给或格纳库单位，每场战斗结束后恢复该玩家整支存活编队100%耐久和EN；不复活阵亡单位，也不额外恢复盾和弹药。第一版不另发驾驶员经验。

## 休息与事件

休息区二选一：恢复全队100%耐久与EN（不复活），或开放个人机库补员。每位玩家可搜索并添加自己的库存机体；服务端按当前剩余部队合计检查编组COST、单机COST、容量、年代、禁用项和库存，房主结束补员后一起返回地图。暂存战利品尚未进入个人库存，不能提前当作补员使用。

八种事件为：战后残骸、失联补给舰队、废弃雷区、隐蔽整备站、缴获作战终端、被困的PMC分遣队、黑市回收商、电磁暴避难所。选择分别侧重资源、机体、科技或修复，部分以耐久、EN或本局资金为代价。事件伤亡同样立即扣库存。黑市交换要求每位参与玩家都有1000暂存资金。

本局任务状态保存在房间内存，可在服务器仍保留房间时重连；服务器重启后不能恢复未撤离的任务和暂存收益。首版不提供跨重启任务存档。

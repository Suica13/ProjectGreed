# 合约模式：战场扫荡（V108 第一版）

创建房间时选择“合约模式 → 战场扫荡”，固定使用“战场扫荡”专用地图，房间展示固定任务封面，不提供选图入口，服务端也不接受改为其他地图。地图提供五个共享部署的PMC席位。队伍1为PMC协作方，队伍2在房间和确认编组界面隐藏；队伍1每个已占用的作战席位（含友方AI）对应一个独立编组的敌军AI，观战者不计入；房主选择敌军阵营、年代和常规编组限制。所有客户端同步查看同一任务路线，由房主选择相邻的下一节点并确认，一起进入战斗或事件。

## 路线与敌军

任务地图嵌入战斗场景的地图区域，复用顶栏与下方聊天、频道、LOG及信息栏展开／收起控件。电脑左侧显示剩余部队，手机将部队列表收纳为折叠面板；事件与补员也在同一区域显示。任务地图期间暂停底层战场渲染，进入节点战斗后恢复。

路线为三条交错连接的分支，无终点；前方节点按需生成，已远离的路线自动回收。节点包括普通战斗、精英战、休息区和随机事件，当前不含商店。每第五层中间为休息区、两侧为精英战，其余层随机生成。

敌军来自所选阵营和年代，并遵守地图环境、禁用标签与AI禁用名单。普通战和精英战的每个敌军AI的编组总COST上限均为房间编组上限的50%，单机COST上限分别为房间单机上限的75%和125%，向下取整。

## 战利品与结算

每位玩家的普通胜利基础奖励为500资金、1000物资、100科技点，乘以 `max(0.25, min(个人入场COST, 房间编组上限) / 2000) × (1 + min(深度, 30) × 0.06)`，分别向下取整。精英战为两倍，并额外奖励一台所选年代的随机机体库存（排除设施、舰船、WIP和驾驶员专属机；单机COST不超过房间单机上限1.5倍或500中的较大值）。科技按携带机体阵营比例分配，排除已满科技阵营。

所有奖励先留在本局，不进入个人钱包或机库，暂存栏显示倍率前数值。完成节点并返回任务地图后，房主可用右上角“撤离战场”使全队一起结算。最终应用现有全局1.25及活动倍率。全体人类玩家部队全灭时强制结算，资金、物资、科技点减半，已获得机体库存完整保留。每人使用独立、可去重的结算收据；库存奖励不授予部署许可。

机体真实阵亡立即扣除个人库存，与常规战、雇佣兵战争统一；不会等到撤离重复扣减。断线本身不判定所有机体阵亡。战斗之间保存耐久、EN、盾、部位、弹药与永久使用次数，回合指令及临时系统不会跨战斗延续。第一版不另发驾驶员经验。

## 休息与事件

休息区二选一：恢复全队最大耐久与EN的50%（上限封顶，不复活），或开放个人机库补员。每位玩家可搜索并添加自己的库存机体；服务端按当前剩余部队合计检查编组COST、单机COST、容量、年代、禁用项和库存，房主结束补员后一起返回地图。暂存战利品尚未进入个人库存，不能提前当作补员使用。

八种事件为：战后残骸、失联补给舰队、废弃雷区、隐蔽整备站、缴获作战终端、被困的PMC分遣队、黑市回收商、电磁暴避难所。选择分别侧重资源、机体、科技或修复，部分以耐久、EN或本局资金为代价。事件伤亡同样立即扣库存。黑市交换要求每位参与玩家都有1000暂存资金。

本局任务状态保存在房间内存，可在服务器仍保留房间时重连；服务器重启后不能恢复未撤离的任务和暂存收益。首版不提供跨重启任务存档。

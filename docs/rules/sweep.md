# 战场扫荡

合约模式下的无限协作PVE，队伍2为敌人AI。房主选择相邻节点并确认，全员同步进入同一节点。路线图沿用战斗布局和下方聊天／LOG，背景与关卡、事件插图仅表现环境设施，不暗示具体敌人或奖励。

路线图从底部向上推进，初次进入和完成节点返回时滚动至底部；每次仅展示到下一场BOSS（含BOSS节点），节点行距固定150像素，使用较粗箭头标示前进方向。路线只连接同列或相邻列，不允许左右两端直接跨连。

## 路线与战斗

每层2至3个候选点，各点有出口且下一层全部可达，每3层强制提供分支，连续单线不会超过3节点。每第5节点全部为BOSS；其余为普通战、精英、休息区或事件。选中节点有锁定动画，系统减少动态效果时停用动画。地图按人数与地面／宇宙设置随机抽选，队友共享部署区。

房间专属设置放在通用战场规则之前，依次选择年代、敌军阵营和作战环境。0093T1是独立年代，可选择联邦或新吉翁敌军。不提供单位科技限制设置，不应用房主科技点上限。玩家单位以所选年代为上限，允许较早年代；0093T1允许携带0079、0083及0087单位，0079T1只能使用带0079T1标签的单位。敌军始终只使用所选年代标签的单位，不向早期年代回退。个人库存与许可要求保持不变。

首节点深度0，增长系数g=1+0.05×深度；不是复利。每个敌军AI编组预算为房间预算×g×类型系数：普通0.5、精英0.75、BOSS1。单机预算原兼容单机上限×g×0.75／1.25／1.5，仍受所选阵营年代和地形约束。引擎预算最多99999。

敌军预算下限按实际所选阵营、年代、地图环境及部署空间内最便宜的合法单位计算，总预算和单机预算至少容纳一台该单位，不再用全阵营奖励池的价格折算敌军下限。生成时同时检查地图部署限制，避免生成不能入场的水面舰艇或大型单位。合法候选池按地图和限制缓存，避免反复扫描。

确认节点、推进路线与创建战斗视为一次操作。生成或部署失败时恢复原节点选择、进度、编队、席位与地图，显示错误并允许重试；玩家掉线时等待重连，不推进节点。不再停留在半完成的最终编组阶段。

每次战斗保留存活单位耐久、EN、盾牌、部件、弹药及驾驶员。存在存活补给或格纳库单位时，整支存活编队战后回满耐久与EN；战损在局内累计，撤离或全灭最终结算时统一扣库存，退出不应用暂存损耗与奖励。补员时排除本局已损失的库存。

## 奖励

普通资源基数1000资金／2000物资／250科技，乘g；精英为2倍、BOSS为3倍。胜利科技再乘1.1。活动倍率在各节点产生奖励时分别应用，四舍五入到25后存入本局；撤离不再乘倍率。

普通战奖励1台、精英3台、BOSS5台，均使用所选年代的独立奖励池。其他年代的BOSS不再额外混入0093单位；0093T1的普通、精英及BOSS均可奖励0093单位。排除战舰及大型运输机，按默认套件COST在当前敌军单机预算50%至125%筛选；池为空则选择最接近该预算的本年代非舰船单位，不用其他年代或舰船填补。机体奖励不授予部署许可；0093库存可在0093T1扫荡中使用，仍需遵守库存、总COST和容量限制。

## 休息区整备

可选择全队恢复100%耐久与EN，或打开当前编队整备。每位玩家每处休息区最多补员3台、遣返3台搭载单位、配属3位驾驶员、遣返3位驾驶员。

补员从母舰格纳库的加号进入个人有库存卡片列表。补员和遣返机体各收取该机体生产物资的1/4，向上取整；遣返有驾驶员的机体前须先遣返驾驶员。驾驶员每次配属或遣返收费500资金。机体原库存没有在入场时扣除，遣返仅释放搭载和预留数量，不额外创造库存。

所有操作先放入本地草稿，顶部实时显示费用、暂存资源图标、总COST、容量点与四类配额。库存、科技、驾驶员、格纳库类型／容量、全局预算或余额不符合条件的候选卡用黑色遮罩并禁用操作。撤销可取消最后操作；取消丢弃整个草稿并回到休息区选项，不收费也不改部队。所有费用从本局暂存资金／物资扣除。

确定时仅提交操作意图，由服务端重新校验整批草稿、一次扣费并替换编队，任一步失败都不修改资源或单位。已确认玩家不能再次提交；唯一请求ID避免重复扣费。全体玩家确认后房主结束整备；已有玩家确认后不能再取消整个服务，防止切换服务重复获得额度。

## 撤离与事件

完成节点回到任务地图后，房主右上角撤离令全体共同结算，显示净暂存收入和机体库存。战斗场景顶部显示整场扫荡的暂存资金、物资及科技点，整备支出实时扣除；最终结算改用实际结算回执，不与暂存值重复叠加。任务地图的收获单位按钮位于节点及获得机体统计右侧。全部玩家部队全灭时强制结束，剩余资金、物资、科技减半并对齐25，机体奖励完整带走。按回执防重。

八类事件为战后残骸、失联补给舰队、废弃雷区、隐蔽整备站、缴获作战终端、被困PMC分遣队、黑市回收商、电磁暴避难所，分别具有环境插图。资源同样逐节点应用线性增长及当时活动倍率；事件伤亡立即扣库存。

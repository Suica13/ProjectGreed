# 合约事件策划编辑器

入口：[admin/contract-event-editor.html](../../admin/contract-event-editor.html)，也可从[管理工具首页](../../admin/index.html)进入。可直接双击HTML离线打开，或在游戏服务器访问 `/admin/contract-event-editor.html`。全部样式、交互和参考事件均内嵌，无需素材目录、联网或个人存档。

这是独立策划工具，不是运行时脚本编辑器。JSON只在本工具中导入，不能当作游戏存档或地图导入；AI根据系统版本号、每项改动标记和文本实施后，游戏才会改变。

## 已整理内容

- 七种基础事件：回收战场资料、消灭小股敌人势力、破坏敌方工厂、占领敌方据点、防守友军据点、上传战场数据、摧毁敌方雷达站。
- 七种联络委托特殊变体：坠落米迪亚的数据、记名联邦MS小队、硝烟野餐驻军、苍白骑士实战测试、运输车队残骸、不死的雷纳斯小队、往事速递的敌方基地。
- 共用规则：当前开放范围、环境筛选、难度阶段、驻军警戒、多人缩放、增援频率与存活上限、演出、收益和撤离。

基础名称和提示读取 `shared/contract-mode.js`；特殊变体名称与委托条件读取 `shared/contact-tasks.js`。更详细的现行行为人工核对后记录于 `contract-editor/catalog.cjs`，属于构建时参考快照。游戏代码改变后需同步此文件和[事件类型记录](../design/contract-task-types.md)，重新构建才能更新工具内模板；导入的策划文件不会被新快照自动覆盖。

## 使用步骤

1. 打开工具即显示15项现有事件；左侧可搜索，或按分类、改动标记筛选。
2. 填写“事件系统版本”，选择事件，设置“无需调整／需要调整／有变动／废弃”。这些是策划标记，不是游戏进度状态。
3. 在概述、触发判定、兵力增援、演出奖励、改动参考五个章节填写内容。新增时可选空白或任意现有模板。切换类型只改变参考类型ID，保留已有文本；新机制应填写稳定类型ID并说明需要实现。
4. 用“共用规则与备注”记录跨事件要求；用“AI交接预览”核对整份策划。
5. “导出全部JSON”保存整份可继续编辑的文档；“导出当前事件”仅导出选中项及共用规则。“导出策划MD”适合交给AI阅读，不能代替JSON重新导入。
6. 下次用“导入JSON”继续编辑。导入会替换当前整份文档，不合并；有未保存改动会先询问，格式无效时不改变当前内容。

工具不自动保存到浏览器，也不访问游戏存档。关闭前请导出；存在未导出的改动时浏览器会尽可能提示。单项导出不会把其他修改标记为已保存。“载入现有事件”恢复本HTML构建时的15项模板，覆盖前先确认。

## 数据格式与实现

`format` 为 `projectgreed-contract-event-planning`，格式 `version` 固定为1；`systemVersion` 由策划填写，`sourceVersion` 记录参考游戏版本。每项事件有稳定 `id`、`type`、`group`、`status`、名称及十二个文本字段。编号不可重复，单次最多200项，JSON文件最多5MB。导出会校验字段，重复编号和错误文件会明确提示。

- 源码：`contract-editor/`，不复制战斗执行逻辑。
- 单独生成：`npm run build:contract-editor`。
- 客户端构建：`npm run build` 自动生成本工具。
- 输出：`admin/contract-event-editor.html` 与 `build/<版本>/admin/contract-event-editor.html`。
- 生成HTML与其他admin生成文件一样忽略提交；维护源码、构建脚本和文档。

服务器仅提供静态HTML，不提供文件写入或事件执行接口。客户端发行包与含客户端的服务端发行包沿用admin打包流程携带本工具；纯服务端包排除此HTML。构建此编辑器不需要执行原生客户端或服务端打包。

# 本地对局记录

设置中的「本地对局记录」默认开启自动LOG、关闭自动回放，保留最近10局，可改为1～100局。一场对局的队伍／全局视角和回放共同占一个保留名额。只有玩家有权收到的战报会被保存，不会绕过战争迷雾。

Windows软件版：现有本地存档目录的 `records/`（设置中可打开存档文件夹）。安卓软件版：已选外置存档目录下的 `records/`；尚未选外置目录时保存在应用内部文件目录。浏览器版：独立IndexedDB，不占用个人存档localStorage；支持文件夹选择的浏览器可在设置中指定外部文件夹，其下创建 `records/`。浏览器清理网站数据会删除IndexedDB记录。文件夹授权丢失时显示错误，需重新选择／授权。

LOG在对局中按增量追加，回放在结算时从服务端取得现有可导出记录并分块落盘；默认不自动生成回放。日志为UTF-8 `.log.txt`，回放为可从原回放入口载入的 `.replay.greed`。旁边的 `.meta.json` 为保留数量和断点续写索引，勿手动单独修改。服务器已有的回放帧数和体积限制仍适用。

超过保留数量只删除本功能创建的旧对局记录，不删除个人存档、手动导出的记录或其他目录。设置中的「查看本地记录」可列出和导出记录。安卓切换外置存档目录后，新记录使用新位置，旧目录中的记录不会自动搬迁。

# 存档编辑器与精简存档

运行 `npm run build` 会同时生成 `public/save-editor.html`；也可运行 `npm run build:save-editor` 单独生成。双击此 HTML 即可离线使用，服务端也提供 `/save-editor.html`。游戏设置中的“下载存档编辑器”可直接取得同一工具，独立 HTML 客户端无需连接服务器。

支持游戏导出的 `ProjectGreed-profile` 个人进度 JSON（版本 1、2、3），以及 Windows / Android 的 `ProjectGreed-app-store` `profile.json`。不编辑独立历史战役存档；打开客户端完整存档时，保留设置、战役备份和其他不属于个人进度的记录。

## 使用

1. 打开存档，修改资源、累计科技点、部署许可、库存、驾驶员或已开发科技。单位及驾驶员支持搜索。
2. 编组页可编辑各阵营的编组 JSON，包含套件选择及预先搭载关系；更换阵营前应用当前 JSON。
3. 点击“保存修改副本”。文件会经过游戏自身的资源、驾驶员、科技及编组校验。PMC 驾驶员属性仍受等级和强化点预算限制，ACE 属性由等级自动计算。
4. 在游戏设置中导入修改后的个人进度；编辑完整客户端存档后，也可退出客户端，再用修改副本替换原 `profile.json`。不要在客户端运行时替换文件。

编辑器只读打开原文件，保存时下载新副本。“导出个人进度”从完整客户端存档提取可跨平台导入的个人进度，不携带客户端设置或战役备份。存档标识和领取历史保留，不提供重置领取记录的操作。基础科技单位本来就拥有许可，编辑器不允许取消这些默认许可。

## 结构

- 个人进度导出升级为 schemaVersion 3：已配属驾驶员资料与名册一致时，编组只保存驾驶员 ID，避免重复保存属性和上传头像。不同的历史资料仍完整保留。
- 奖励领取记录按对局分组、提取公共 ID 前缀，全部领取记录都保留，用于防止重复发放。
- 运行时资金与科技存储也使用同一无损领取记录编码；数据较小时保持普通 JSON。旧记录在下次正常写入时使用精简编码。
- 客户端和编辑器共用 `shared/save-codec.js`、`client/profile-save-core.js` 与游戏校验规则，旧版 1 / 2 存档继续可读。
- 本次不清除历史活动及待领取邮件中的套件字段；旧套件记录不再展示或产生套件奖励，新活动不再接收、配置或保存套件赠送。

校验截图、日志和测试产物统一位于 `tmp/verification/`，不放入正式 `build/` 包。

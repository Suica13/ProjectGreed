# 任务树编辑器

执行 `npm run build:task-editor`，或正常执行 `npm run build`，生成可双击离线使用的 `public/task-tree-editor.html`。独立交付文件同时保存在 `build/<版本>/ProjectGreed-<版本>-task-tree-editor.html`，不需要服务器或游戏存档。

左侧选择任务设计节点、合约事件、剧本触发条件、剧本动作、胜利条件或联络任务要求；中间查看树与分支；右侧修改名称、描述、前置节点、连线文字和事件参数。先选节点再添加类型，会创建它的子节点；前置节点选“无”可创建另一棵树。支持搜索、缩放、定位、撤销、重做与本地草稿保存。

对话支持逐句添加角色名、镜头聚焦单位、文本、头像和声音路径。复杂组合条件、选项与奖励对象使用JSON字段；输入错误时会提示且不保存该参数。

“导出设计JSON”保存全部节点、任务设置和事件参考；“导出AI制作说明”生成可直接发送给AI的文本文件，包含结构化设计、目前支持的类型及语义、原生字段名、待补全规则和实现注意事项。“预览 / 校验”检查设计结构、引用与循环，但不代替游戏运行验证。

可以重新导入设计JSON，或导入含 `mission` 的现有地图JSON。地图导入后会将原有触发条件、动作与胜利条件转换为设计节点，同时保留原始地图作为参考。对树的修改不会自动回写该原始地图。

本工具是任务设计编辑器，导出的树不是可直接运行的地图。AI仍需补全地图坐标、机体套件、部队配置、分支条件与奖励，并通过共享 `MissionMode.validate` 及实际游戏回归。合约目标、联络委托和剧本事件分别属于不同系统，参考说明会明确区分。树的连线不自动赋予运行时顺序；需要前置依赖时应实现 `event_completed` 或组合条件，需要选项分支时应实现 `choice` 与 `choice_selected`。

事件类型来自 `task-editor/catalog.cjs`，合约目标直接读取 `shared/contract-mode.js` 的现有类型与描述；测试核对剧本动作和触发类型与 `shared/mission-mode.js` 的白名单一致。工具不运行用户脚本，不访问个人存档，不改变游戏规则。

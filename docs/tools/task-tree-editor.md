# 联络人委托策划树

打开 `admin/task-tree-editor.html` 即可离线编写。`admin/index.html`为管理工具入口；服务器入口为`/admin/`。运行`npm run build:task-editor`或正常`npm run build`生成HTML，独立交付副本在`build/<游戏版本>/admin/`。

本工具只编写策划文档，不连接游戏、不读取实际委托／单位／科技数据，不编辑源码或玩家存档，也不验证委托运行逻辑。

现有基准按联络人独立保存：[联邦联络人 1.3 JSON](../data/contacts/efsf-联邦联络人-1.3.json)（12项已接入，另有3项未来策划）、[阿纳海姆 1.0 JSON](../data/contacts/anaheim-1.0.json)（10项委托）、[吉翁联络人 JSON](../data/contacts/zeon-吉翁联络人-1.0.json)（11项委托）。每份文件只含一位联络人，其`portrait.dataUrl`内嵌游戏原头像；`portrait.id`与`portrait.source`记录素材来源。单独复制JSON即可保留头像。在工具中点击“导入JSON”并选择文件，可继续修改策划；导入会替换当前草稿，请先分别导出需保留的联络人。旧版多人JSON仍可导入。

点击“联络人文本 / 头像”可预览、更换或移除头像；支持最多1MB的PNG、JPEG与WebP。点击“导出当前联络人JSON”只保存所选联络人、头像、全部委托及当前版本和备注，文件名包含联络人编号、名称与系统版本。预览与AI制作说明同样仅包含当前联络人。

联邦策划保留初见与交付对话、目标、初始装备、奖励及前置关系；`systemVersion`为`1.3`。本轮只接入小菜一碟和财不外露，其他状态标记与未来草稿保留；不是自动执行配置，游戏后续变化不会自动同步到此文件。

策划填写：

- **委托系统版本号**：自由填写，例如`1.0`、`方案B-2026.11`。这是本套委托策划版本，不是游戏版本；JSON的`version:1`则仅表示文件格式版本。
- **委托名称与策划文本**：目标、条件、奖励、初始装备、对话和特殊要求均写成自由文本，不需要程序字段。
- **委托改动标记**：`无需调整`、`需要调整`、`有变动`、`废弃`。这些是交给AI判断改动范围的策划标记，不是玩家的接取或完成进度。
- 可选的前置委托、联络人通用文本和全局备注。

新增委托默认标为`需要调整`。选中一项再新增，会以前者为前置；“独立委托”不设置前置。前置可以多选以表达分支与汇合。`废弃`保留记录并提醒AI停用；删除卡片则直接删除文档条目，两者含义不同。

导出JSON包含版本、稳定委托编号、标记、文本和关系，以及四种标记的含义。导出AI制作说明生成可直接交给AI的文本文件，要求先核对系统版本号，再决定每项委托是否实现或更新；`无需调整`只能参考，`废弃`不得擅自清除玩家存档。支持JSON导入、草稿保存、撤销重做、按标记筛选与搜索。

管理工具统一位于`admin`：地图编辑器、单位编辑器、委托策划树、存档编辑器和活动管理。精简开发者编辑器显式构建后输出至`admin/developer.html`，仍使用独立服务和既有密钥认证；游戏服务器不提供其编辑API。构建和打包脚本已同步目录，`public`只保留游戏客户端生成文件。

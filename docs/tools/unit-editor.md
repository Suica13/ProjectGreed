# MS 单位工坊

直接打开 `public/unit-editor.html`（无需服务端或登录）。服务器也提供 `/unit-editor.html`，地图编辑器顶部有入口。`npm run build:unit-editor` 可单独构建，正常构建也会更新。

## 制作流程

1. 选择吉姆、扎古 II 或 RX-78-2 并复制为新单位，设置不与现有目录冲突的 ID、名称和编号。原始模板不被修改。
2. 选择部件图层，替换共用贴图或为该层导入独立 PNG/JPEG/WebP。可设置图标、绑定骨骼、绘制顺序、缩放/镜像、旋转、偏移及横向贴图帧参数。骨骼参数影响所有绑定部件；图层参数仅影响当前层。
3. 切换套件、持握武器、移动/攻击/盾牌状态和地面/宇宙环境。在画布缩放观察像素网格及骨骼，金色标记表示当前武器的图层枪口（复杂多枪口仍继承模板配置）。
4. 设置图层的套件、持握武器和攻击状态条件。条件之间为 AND；保留选项不会删改模板已有规则。完整 JSON 支持现有运行时变量、数组以及 `{"not":...}`。原有 `weaponDisplayIndex`、`requiredParts` 等约束仍然有效，所选层会显示当前是否可见。
5. 动画显隐区间示例：`{"clip":"Common_Melee_A","start":0.1,"end":0.5,"visibleInside":true}`。空对象清除区间。
6. 时间轴播放、暂停、拖动或按 1/30 秒步进。选择图层的骨骼和 x/y/dir/height 字段，在当前时间添加或替换关键帧，列表可跳转与删除。位移值相对骨骼基础位置，角度为度。可以复制动画、修改时长，并将新动画绑定给武器。
7. 保存 `.pgunit.json` 工程可保留所有素材并重新导入；导出单位 ZIP 包供项目注册。撤销/重做最多30次；关闭前请保存。

## 注册到游戏

解压单位包，将 `assets/units/<新ID>` 放入同版本仓库。执行 `npm run units:reload`，它会完整验证配置并注册、构建客户端。不要覆盖现有单位目录；如果目录加载器报错，先处理报错再注册。构建之后重启服务器，并使用新版客户端。

导出的是源配置，不将运行时伤害倍率/AP等派生数值写回；保留模板武器、原生来源与时间信息。所有单位贴图和骨骼动画已包含，共用弹体、音效和特效仍依赖原仓库。此版本不提供武器伤害/科技树编辑、任意原 MOD INI 导入、完整战斗模拟或独立 MOD 包。复杂变形和炮塔单位不在内置模板范围。

## 校验

`node --test tests/unit-authoring.test.cjs` 验证模板复制、错误引用、共享渲染器显隐/采样，以及三个导出单位经真实目录加载器注册校验。预览直接引用 `client/renderer.js`，不另写骨骼渲染算法。浏览器视觉验收尚需在有浏览器的环境完成。

## RW_GW 导出（V76）

点击顶部“导出 RW_GW 单位”。原生映射来自 `Suica13/RW_GW` 的 `34d7d92f63f34ac527021455b4c221523408b011`（main），仅支持内置三个模板。导出 ZIP 含新单位 INI、PNG 和来源/限制报告。

将 ZIP 中 `GW_BattleUniverse_DLC_0079` 合并到同版本 MOD 副本。新单位通过 `copyFrom: ROOT:Units/BattleUnits/<模板>/<模板>.ini` 继承原生逻辑，不能单独作为 MOD 加载。通过沙盒搜索新 ID 试用；不自动加入建筑生产菜单和科技树。原 MOD 仓库没有被修改。

- 支持原图层贴图、偏移、缩放、镜像、旋转、层级及骨骼位置修改，图标替换、隐藏/删除已有图层。导出图片须为 PNG。
- 改动的已有骨骼动画转换回 arm/leg 轨道和秒数，并保留未映射的原生附加轨道与播放设置。未改动画完全继承源模板，避免把网页特有简化覆盖到原 MOD。
- 可转换已有套件、持握索引、攻击/移动/盾牌/面罩条件；保留未替换的原生破损等条件。复杂 OR 条件、无法区分的同索引武器会阻止导出。
- 尚不支持新增/重命名图层、全新动作链、动画时间窗口显隐、修改武器枪口/射击动画绑定、变形或数值的反向转换。发现这些修改时给出原因并阻止生成 ZIP，不静默丢弃。
- 网页附加的 BoostLoop 层没有原生映射，未改动时保留原 MOD 推进表现；若编辑了该附加层则阻止导出。
- 驾驶员、攻击、资源和原单位的变形/改造行为均继承；变形或改造目标仍是原 MOD 单位，不自动生成自制衍生单位。

验证：`node --test tests/rw-unit-export.test.cjs`。已检查三个模板继承路径、骨骼/显隐/动画输出与不支持修改的阻断。尚未进行 Rusted Warfare 引擎实机验收；请先在 MOD 副本测试。更新源仓库映射时运行 `python tools/capture-rw-templates.py /path/to/RW_GW`，检查差异后重建编辑器。

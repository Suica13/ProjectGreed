# 构建体积与工作区清理

`public/` 是本地生成目录，已退出Git跟踪并整体忽略。初次检出和更新源码后执行 `npm.cmd ci`（依赖变化时）及 `npm.cmd run build`，再启动服务器。完整发行使用 `npm.cmd run release:all`，Windows、Android、含客户端的服务端文件夹和完整独立HTML均放在 `build/<版本号>/`。

独立HTML保留全部现用BGM、贴图、音效和游戏逻辑，不依赖网络或旁置音乐文件。V136整理前体积为160249566字节，其中音乐在压缩前的JSON中约81 MB。PNG和MP3本身已压缩，完整单文件仍会明显大于纯代码页面。

资源池统一保存头像、科技图标、音乐、贴图和音效的重复数据；完全相同的曲目可保留多个播放列表条目，但只保存一份二进制内容。资源池兼容读取旧版本，并在加载时恢复原字段。客户端宿主与HTTP分发继续使用同一个生成HTML，不复制玩法逻辑。原生构建会剔除已不再引用的旧资源及脚本。

## 可重复执行的工具

- `node tools/audit-client-size.cjs`：只读统计HTML、目录数据、媒体和BGM的大小。可在命令末尾指定另一个HTML文件。
- `node tools/clean-workspace.cjs`：只预览可清理目录及占用。
- `node tools/clean-workspace.cjs --apply`：只删除隔离测试的Windows WebView缓存、Gecko浏览器测试配置和Python字节码。保留测试结果、截图、Windows隔离测试的profile.json、正式发行产物、实际玩家存档、服务端数据及日志和SDK缓存。删除前校验绝对路径，拒绝越出工作区的链接。

移植脚本仍在tools/。导入清单、审计JSON和旧武器时间线CSV统一归档到docs/imports/reports/，相关生成器及读取路径同步更新。保留来源证据，不因旧版本号删除仍可复用的移植工具。

未被当前播放列表引用的旧BGM已移除。当前13个曲目条目保留，两个完全相同的Battle曲目共用同一份原始MP3，未转码或降低音质。

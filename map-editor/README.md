# 地图编辑器

直接用浏览器打开 `public/map-editor.html`，或在游戏设置中点击“地图编辑器”。运行服务端后也可访问 `/map-editor.html`。编辑器无需连接服务端，导入的图片不会上传。

## 制作流程

1. 在“地图”页设置行列数、Tile像素尺寸、默认环境、队伍和玩家数量。每个玩家都有一个出生地与矩形部署区，可以输入坐标或在画布上点选/框选。同队部署区在游戏里共享。
2. 在“图块”页设置切片宽高、边距和间距，再导入图集。点击图集或精确选择框选取Tile。按住Shift在图集上选择矩形，可使用多格画笔。
3. 每种Tile可以设置地面/宇宙环境、普通/水/山/林/废墟/雪地/沙漠地形，以及装饰和动态标记。高地是旧地图的兼容类型。Tile属性作用于所有引用该Tile的格子。
4. 在右侧管理图层。图层可在地面单位下方或上方显示；上方图层仍位于空中单位下方。“仅装饰”图层不覆盖地形属性。不透明度为0的非装饰层可以用作不可见地形层；取消“可见并参与导出”会同时排除它的显示与地形贡献。
5. 可以导入整张PNG/JPEG/WebP/GIF作为装饰地图图层，默认铺满现有地图。位置和尺寸以格为单位在右侧调整。原图及透明通道会嵌入导出文件。
6. 使用画笔、删除、油漆桶、方框（实心/空心）、直线、选择工具。选择后可以拖动整块区域，也可复制、剪切和粘贴。支持40步撤销/重做。
7. “规则”页支持带权重的随机候选和九宫格。随机结果由种子决定并固化为具体Tile。九宫格使用矩形工具，边缘和中心重复铺设。选择图集Tile后新建九宫格，会以该Tile为左上角读取右下方3×3，也可逐格重新绑定。

快捷键：B画笔、E删除、F油漆桶、R方框、L直线、M选择；空格/中键平移，滚轮缩放；Ctrl+C/X/V操作选区，Delete删除，Ctrl+Z撤销、Ctrl+Shift+Z或Ctrl+Y重做，Ctrl+S导出工程。

## 导出和游戏注册

- **导出工程**：`.pgmap.json`，保留图层、图片、Tile属性、动态标记、玩家配置和规则，可继续编辑。
- **导出游戏地图**：`.json`，同时包含可继续编辑的工程及合成后的地形、环境矩阵、部署区和模式标记。会检查当前游戏兼容性。
- **导入地图**：支持上述两种文件及项目现有的传统地图JSON。文件校验失败时保留当前工程。

在项目根目录注册导出的游戏地图或工程：

```powershell
npm.cmd run maps:import -- "地图文件路径.json" --check
npm.cmd run maps:import -- "地图文件路径.json"
npm.cmd run build
```

`--check`只校验，不写文件。注册时完整校验目录后才保存至`assets/maps/<ID>.json`并更新`assets/unit-catalog.json`；同ID地图会覆盖对应文件。完成后重启服务端，并让玩家使用重建后的客户端。

当前引擎支持2队、每队1–5名玩家。编辑器能保存2–8队工程，多队对战机制尚未接入，因此3–8队配置不能注册为游戏地图。部署区须包含出生地、互不重叠，并满足当前目录规定的72个可通行格。山和水不计入此项容量。雪地、沙漠当前采用普通地面的移动成本与掩护数值；宇宙/地面属性按每格参与适应性、移动、索敌和表现计算。

Tile像素宽高用于图集切片和编辑画布；当前战斗仍使用正方形战术格，图像按格映射。

动态图块及图层只保存标记和初始状态，暂不触发事件。普通、快速战默认都启用，可分别关闭。地图模式限制由服务端检查。

单文件上限64MB；单图上限36MB、长宽8192px。地图上限128×128格，Tile尺寸4–512px，最多32个图层和16384个Tile。编辑器与游戏使用视口绘制及图层缓存，不会为高缩放地图创建整幅超大Canvas。

## 源码

- `shared/map-document.js`：格式校验、地形合成和编辑操作。
- `shared/tilemap-view.js`：编辑器与游戏共用的图层绘制。
- `map-editor/editor.html/css/js`：独立编辑器界面。
- `tools/build-map-editor.cjs`：构建为可直接打开的单HTML；正常`npm run build`会自动构建。
- `tools/import-map.cjs`：校验和注册地图。
- `client/tilemap-renderer.js`：游戏中的视口缓存。

专项检查：`node --test tests/map-editor.test.cjs`、`npx playwright test tests/map-editor.spec.cjs tests/map-editor-network.spec.cjs`。
